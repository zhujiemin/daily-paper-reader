## 摘要
生成模型的快速发展显著加剧了被操纵图像检测的问题，因为这些方法能够生成高度逼真的伪造内容，从而进一步凸显了多媒体取证的重要性。传统方法通常将图像操纵检测构建为二分类任务（真实 vs. 生成），这限制了对不同操纵形式进行区分和定位的能力。为解决这些限制，本文通过引入统一的多分类框架（真实 vs. 完全生成 vs. 篡改）扩展了现有检测器。除了对图像真实性进行分类外，该框架还包含一个分割分支，以实现对篡改区域的像素级定位。所提方法优于选定的近期基准方法，提供了一种高效解决方案，在分类准确率上有所提升，并在定位任务中取得了更高的 IoU 分数。代码见：https://github.com/anngal01/From-Detection-to-Localization-A-Unified-Forensics-Framework-for-Fully-Synthetic-and-Tampered-Images。

## Abstract
The rapid advancement of generative models has significantly worsened the problem of manipulated image detection, as these methods are capable of producing highly realistic forgeries, reinforcing the importance of multimedia forensics. Conventional approaches typically frame image manipulation detection as a binary classification task (real vs. generated), which limits the capability to distinguish and localize different forms of manipulation. To address these constraints, this work extends an existing detector by introducing a unified multiclass framework (real vs. fully generated vs. tampered). In addition to classifying image authenticity, the framework incorporates a segmentation branch to enable pixel-level localization of tampered regions. The proposed approach outperforms selected recent benchmarks, offering an efficient solution with improved classification accuracy and higher IoU scores for the localization task. ## 1. 核心问题与研究动机

- **背景**：扩散模型（Latent Diffusion、DALL·E 3、Midjourney 等）能够大规模生成高度逼真的图像，使得虚假信息与身份欺诈风险显著上升，多媒体取证的重要性被进一步强化。
- **现有瓶颈**：
  - 主流检测器多为**闭集二分类**（真实 vs. 生成），只能给出图像级标签，无法区分“完全合成”与“局部篡改”，更无法定位篡改区域。
  - GAN 时代的频谱伪影、上采样痕迹在扩散模型中大幅减弱，旧方法迁移性差。
  - 高性能 LVLM（如 FakeShield、So-Fake-R1、SIDA）虽具备推理能力，但**参数庞大、推理延迟高、像素级精度不足**，难以落地到实时场景。
  - 缺乏同时涵盖“真实 / 完全合成 / 局部篡改”三类样本的统一基准，长期阻碍多分类取证研究。
- **整体含义**：论文主张将图像取证从“二分类检测”推进到**统一多分类 + 像素级定位**的新范式，并在精度与效率之间取得更好平衡。

## 2. 方法论

### 2.1 核心思想
- 基于**冻结的 DINOv2** 骨干网络构建双分支架构：检测分支做三分类（Real / Tampered / Fake），定位分支仅在被判为 Tampered 时激活，输出像素级掩码。
- 关键洞察：CLIP 类模型存在“proxy token”现象，注意力集中在少数代币上，空间一致性差；DINOv2 的注意力图与图像内容对齐，patch 间相关性更强，更适合稠密预测任务。

### 2.2 检测分支
- **特征提取**：DINOv2 编码器输出 n 个 CLS token（维度 d），拼接后经可学习投影网络 P1。
- **TIE 模块**（Trainable Importance Estimator）：为每个 token 分配权重，沿第二维求和得到每图单一特征向量，再经 P2 投影。
- **分类头**：两层 d×d 全连接（ReLU）+ 一层 d×3 线性层，softmax 输出三类概率。
- **训练目标**：
  - 分类交叉熵损失 **L_CCE**（标准多分类目标）。
  - 监督对比损失 **L_Cont**：拉近同类特征、推远异类特征，温度参数 τ 控制分布锐度。
  - 总损失：**L = L_CCE + ξ·L_Cont**，ξ 为可调超参。

### 2.3 定位分支
- **条件激活**：仅在图像被判为 Tampered 时运行，节省计算。
- **特征提取**：复用前向计算的 patch token（通常被丢弃），取 DINOv2 base 的 {3, 6, 9, 12} 层；因各层 patch 分辨率一致，浅层空间细节得以保留。
- **特征融合**：
  - token 序列 reshape 成 2D 特征图，1×1 卷积升维，scratch 层统一通道。
  - 渐进式融合：深层上采样后与浅层**逐元素相加**（非拼接），保持维度效率；融合后经两阶段残差精炼模块。
  - 4 层特征共进行 3 次融合。
- **掩码解码**：U-Net 风格解码器，两个上采样阶段（256→128→64 通道），GroupNorm + ReLU + 残差捷径，末端 3×3 精炼块与 1×1 卷积输出单通道掩码。
- **训练目标**：**L = L_BCE + L_DICE**，等权组合，兼顾像素级分类与区域级重叠一致性，缓解篡改像素占比低的类别不平衡问题。

## 7. 优点

- **统一框架设计**：将“真实 / 完全合成 / 局部篡改”三分类与像素级定位整合在一个模型中，突破传统二分类的结构性限制。
- **骨干选择有据**：从 proxy token 现象出发论证 DINOv2 优于 CLIP，而非经验性堆叠。
- **条件式定位分支**：仅在检测为 Tampered 时激活，兼顾精度与效率，避免无意义计算。
- **参数高效**：冻结骨干、仅训练轻量投影与解码器，训练轮数少、调参空间小，工程落地友好。
- **精度—效率双优**：在定位 IoU 大幅领先的同时，参数量与延迟远低于 LVLM 方案。
- **可复现性**：代码已开源，预处理与训练细节描述较完整。

- **类别定义依赖标注**：三分类要求数据同时包含完全合成与局部篡改样本，现实中此类标注成本高，泛化到新域可能受限。
- **算力信息不透明**：未披露训练 GPU 数量与时长，复现成本难以预估。
- **应用限制**：条件式定位依赖检测分支正确判为 Tampered，检测误判会直接导致定位缺失；对极小篡改区域和低置信度场景仍不可靠。
