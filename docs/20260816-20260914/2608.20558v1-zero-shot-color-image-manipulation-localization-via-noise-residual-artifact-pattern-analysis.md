## 摘要
数码相机通过去马赛克、相机内后处理和有损压缩，将设备特定的伪影嵌入每幅采集图像中。这些痕迹构成了一种可用于评估图像真实性的取证信号。现有的被动方法主要依赖 Bayer 残差的绿色通道，丢弃了其余颜色通道中可用的相关信息，并且通常需要训练数据或设备注册。这项工作提出了一种零样本、免训练的盲图像篡改定位流程，该流程直接从单幅可疑图像的噪声残差中估计参考伪影模式，无需假设固定的滤波器配置、颜色布局或块周期。该流程包含基于采集噪声与插值噪声方差比的原则性去噪器选择准则、针对估计参考模式的块级相关性分析，以及生成像素级篡改概率图的双分量高斯混合模型评分阶段。消融研究评估了去噪器选择和块大小对定位精度的影响，并与最先进的被动方法进行比较，证明了所提零样本方法的竞争力。

## Abstract
Digital cameras embed device-specific artifacts into every acquired image through demosaicing, in-camera post-processing, and lossy compression. These traces constitute a forensic signal that can be exploited to assess image authenticity. Existing passive methods rely predominantly on the green channel of the Bayer residual, discarding the correlated information available in the remaining color channels and typically requiring training data or device enrollment. This work proposes a zero-shot, training-free blind image manipulation localization pipeline that estimates a reference artifact pattern directly from the noise residual of a single suspect image, without assuming a fixed filter configuration, color layout, or block period. The pipeline incorporates a principled denoiser selection criterion based on the acquired-to-interpolated noise variance ratio, a block-level correlation analysis against the estimated reference pattern, and a two-component Gaussian Mixture Model scoring stage that produces a pixel-level tampering probability map. An ablation study evaluates the impact of denoiser choice and block size on localization accuracy, and comparisons against state-of-the-art passive methods demonstrate the competitiveness of the proposed zero-shot approach.

- **现有方法的痛点**：

  - 多数方法需要**参考图像、设备指纹库或有标注的伪造数据做监督训练**，在无这些资源的真实场景中不可用。
- **本文定位**：提出**零样本、免训练**的盲图像篡改定位流程，仅凭**单张可疑图像**，不假设固定滤波器配置、颜色布局或块周期，直接从全彩噪声残差估计参考 CFA 伪影模式并定位篡改区域。

## 2. 方法论

### 2.1 核心思想
- 真实成像区域在噪声残差中保留**周期性的 CFA 插值指纹**；篡改（拼接、复制—移动、对象移除、AI 合成）会破坏这种统计一致性，使局部残差与参考伪影模式的相关性显著下降。
- 因此可用「块级相关性 → 双分量 GMM → 后验概率图」的方式，把"与参考模式一致"作为真实性假设。

### 2.2 关键技术细节与流程

- **噪声残差模型**：`W = I − Dθ(I)`；简化传感器模型 `I = I0 + I0K + Θ`（K 为 PRNU 乘性场，Θ 为加性噪声）。给定同设备 N 张图，PRNU 指纹由最大似然估计 `K̂ = Σ W(i)I(i) / Σ (I(i))²` 得到。

- **第一步：去噪器选择（原则性准则）**
  - 定义采集/插值噪声标准差比 `ρ(θ) = σA(θ) / σI(θ)`，其中 σA 为相机采集块残差标准差、σI 为合成插值块残差标准差；ρ 越高表示保留真实相机噪声、抑制插值伪影的能力越强。
  - `θ* = argmax_{θ∈Θ} ρ(θ)`，对三类 skimage 去噪器做超参扫描：
    - 小波去噪：分解层数 L∈{1..5}、估计噪声 σ̂∈[0.001,0.1] 步长 0.001、小波族 haar/db4/db8/sym4/sym8/bior4.4；
    - TV 去噪（Chambolle）：正则权重 λ∈{0.02,0.05,0.10,0.20,0.50}；
    - 双边滤波：窗口 w∈{3,5,7,9}、σr∈[0.001,0.1] 步长 0.001。
  - 结果：`denoise_tv_chambolle`（λ=0.002, ε=0.001）取得最高 ρ=2.414，优于小波（1.717）与双边（1.235），被选入后续阶段。小波分析显示 **L=1（浅层分解）**通常最优。

- **第二步：参考伪影模式估计**
  - 对每个颜色通道独立计算残差 `Wc = Ic − Dθ*(Ic)`，c∈{R,G,B}。
  - 将单通道残差划分为 K 个不重叠 B×B 块，构造两种候选参考模式：
    - 带符号均值 `P(1)c = (1/K) Σ Bk`（保留噪声波动符号）；
    - 绝对值均值 `P(2)c = (1/K) Σ |Bk|`（强化周期性结构的幅度、不区分极性）。
  - 用 **DCT 周期性判据**选模式：对候选做二维 DCT，排除 DC 系数后取非 DC 系数幅值总和最大者，即 `P*c = argmax Σ_{(u,v)≠(0,0)} |P̂(u,v)|`。所选模式决定后续使用的残差形式（Wc 或 |Wc|）。

- **第三步：块级相关分析**
  - 特征图 `F(i,j) = corr( vec(P*), vec(B*ij) )`，其中 P*、B*ij ∈ R^{B×B×C}，vec(·) 把三个颜色通道拼接为单一向量，corr 为 Pearson 相关系数。
  - 真实块与 P* 的伪影模式统计一致，F 接近 1；被篡改块的相关性接近 0。

- **第四步：GMM 概率评分与二值化**
  - 将 {F(i,j)} 建模为双分量高斯混合 `p(f) = Σ_{k=1}^{2} πk N(f; μk, σk²)`，参数用 EM 估计。
  - **均值较大**的分量视为真实（authentic）总体，另一分量为篡改总体；每块取属于篡改分量的后验概率，得到像素级软篡改图 T（块内像素继承该块得分）。
  - 用 **Otsu 法**确定阈值 τ，二值化得到定位掩码 `S(i,j) = 1 if T(i,j) > τ else 0`。

## 6. 主要结论与发现

- 在 RTD 上，所提方法取得**最高 Precision (0.825)、AUC (0.839)、IoU (0.725)、MCC (0.483)**，优于 Ferrara、González、Park 三种方法；AUC 相比次优方法 [14]（0.781）的提升说明软篡改图 T 在所有阈值下都能更可靠地排序篡改像素。
- Park [25] 取得最高 Recall 与 F1，但 Precision (0.689) 与 IoU (0.155) 偏低，提示可能存在**严重过分割**；Ferrara [11] 在所有指标上一致偏低，反映早期手工特征方法在多设备 RTD 上的局限。
- **块大小消融**：B ∈ {8, 12} 略优于极端值 B=4 与 B=24；B=12 在"相关性可靠性 vs 空间分辨率"之间取得最佳折中。块过小相关估计支撑不足，块过大降低空间分辨率并可能跨越真实/篡改边界。
- **设备依赖性**：Nikon D7000、Nikon D90、Sony A57 三款设备结果稳定（AUC>0.85，F1 0.55–0.67，MCC 0.43–0.59），数据集均值 AUC>0.82、MCC>0.40；**Canon 60D 是明显异常值**（MCC 在 −0.09~0.30 波动，AUC 0.47~0.70），其专有图像处理产生的非典型伪影在现有流程的任何单一固定块大小下都无法可靠捕获。
- 一个值得注意的观察：除预期的 2×2 CFA 周期模式外，Canon 60D 示例中出现**意外的 3×3 模式**，且仍能据此准确定位篡改区域——说明该流程对非标准周期结构具有一定适应性。
- 未来工作方向：扩展到更多取证基准、与同样零样本约束的方法比较、面向设备自适应块大小选择（用 DCT 能量判据做数据驱动搜索）、以及处理 AI 生成/扩散式篡改（其噪声结构未必按可预测方式破坏 CFA 痕迹）。

## 7. 优点

- **真正的零样本、免训练**：不需要参考图像、设备指纹库或标注伪造数据，仅用单张可疑图像即可工作，实用性强。
- **充分利用全彩信息**：以通道感知方式使用 R/G/B 三通道残差（而非仅绿色通道），并把三通道向量化后统一计算相关性，保留通道间相关信息。
- **去噪器选择有原则**：提出采集/插值噪声方差比 ρ 作为可量化、可扫描的准则，把"去噪强度"这一关键超参从经验试错变为优化问题（`argmax ρ`）。
- **参考模式自适应估计**：同时考虑带符号均值与绝对值均值两种模式，并用 **DCT 非 DC 能量**作为周期性判据自动选择，无需预设 CFA 布局、滤波器配置或块周期。
- **概率化输出与合理阈值化**：双分量 GMM + EM 给出软篡改概率图，既支持 AUC 这类阈值无关评估，又可用 Otsu 自动二值化；"均值较大的分量为真实"这一假设简单且可解释。
- **评估指标选择专业**：在类别极度不平衡的像素级任务中同时报告 MCC 与 AUC，避免仅用准确率/F1 造成的误导。

## 8. 不足与局限

- **实验覆盖窄**：仅一个数据集（RTD）与四款相机；跨数据集、跨压缩条件、跨篡改类型的泛化性未被验证（作者自述相关工作仍在进行中）。

- **设备泛化风险**：Canon 60D 上近乎失效（MCC 可低至 −0.09，AUC 低至 0.47），表明方法对去马赛克实现差异敏感，鲁棒性不足；文中未给出针对该失效模式的修复方案。
- **块大小固定候选集**：B 只能从 {4,8,12,24} 等预设值中选取，无法自适应设备特定周期（作者也把自适应块大小列为未来工作），这直接限制了在非标准周期设备上的表现。

- **算力与效率信息缺失**：无任何运行时间、计算开销或硬件描述，难以评估实际部署可行性。
- **AI 生成内容不适用**：生成式/扩散模型编辑不会以可预测方式破坏 CFA 插值痕迹，合成内容可能自带连贯噪声结构，当前框架未处理该场景（仅列为未来方向）。
