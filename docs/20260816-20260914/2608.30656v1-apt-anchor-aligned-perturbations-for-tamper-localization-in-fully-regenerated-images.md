title_zh: APT：用于完全重生成图像篡改定位的锚点对齐扰动
authors: "Suhyeon Ha, Woo Jae Kim, Joonsung Jeon, Sooel Son, Sung-eui Yoon"
date: 2026-08-31

tags: ["query:image-tamper"]
score: 10.0
evidence: 在完全重生成设定下通过嵌入不可感知信号实现像素级篡改定位
tldr: 现有主动篡改定位假设拼接式篡改，嵌入信号在背景中保留；但扩散修复会整图重生成，破坏背景信号，使现有框架失效。作者提出 APT，在潜空间嵌入半脆弱、逐向量的锚点对齐扰动，使空间特征向量趋向固定锚点方向，再根据修复后前景与背景的对齐差异定位篡改。在 COCO 上，APT 的全重生成 IoU 达 0.92，超过最强基线 WAM 的 0.84，而现有方法 AUC 近 0.5，表明其可泛化至未知篡改类型。

## 摘要
主动式篡改定位在图像分发前嵌入不可感知信号，从而实现像素级操纵检测。现有方法假设拼接（SP）设定，其中合成区域被合成到原始背景上，嵌入信号保持完整。然而，现实世界中基于扩散模型的图像修复运行于完全重生成（FR）设定，整幅图像都会经历去噪，从而破坏背景信号，使现有框架失效。我们提出 APT，一种半脆弱隐空间扰动，嵌入密集的、逐向量定位信号。通过将每个空间特征向量对齐到固定锚点方向，APT 利用修复后合成前景与锚点对齐背景特征之间的对齐差异来定位篡改。所提出的难负样本挖掘损失和含噪扰动分支进一步强制统一对齐。在 COCO 上的实验表明，APT 达到 0.92 的 FR IoU，优于最强基线（WAM，0.84），而现有方法退化至接近随机的性能（AUC 0.5），从而确立 APT 为一种实用的取证框架，可泛化至测试时未知的篡改类型。

## Abstract
Proactive tamper localization embeds an imperceptible signal into an image prior to distribution, enabling pixel-level manipulation detection. Existing methods assume a spliced (SP) setting, where synthesized regions are composited onto the original background, leaving embedded signals intact. However, real-world diffusion-based inpainting operates in a fully regenerated (FR) setting, where the entire image undergoes denoising, disrupting background signals and rendering existing frameworks ineffective. We propose APT, a semi-fragile latent-space perturbation that embeds a dense, vector-wise localization signal. By aligning each spatial feature vector toward a fixed anchor direction, APT localizes tampering via the alignment disparity between synthesized foreground and anchor-aligned background features after inpainting. The proposed hard negative mining loss and noisy perturbation branch further enforce uniform alignment. Experiments on COCO demonstrate that APT achieves an FR IoU of 0.92, outperforming the strongest baseline (WAM, 0.84), while existing methods collapse to near-random performance (AUC 0.5), establishing APT as a practical forensic framework generalizable across tampering types unknown at test time.

## 1. 核心问题与整体含义

- **研究背景**：扩散模型驱动的图像修复（inpainting）能以极高真实感生成篡改图像，显著降低了伪造门槛，威胁社交媒体与公共信息真实性。
- **主动式取证思路**：在图像分发前嵌入不可感知信号，事后由验证方检测并定位被篡改区域。
- **关键问题（本文核心动机）**：
  - 现有主动式篡改定位方法均假设**拼接（Spliced, SP）**设定——伪造区域被贴回原图，背景像素完全保留，嵌入信号不受影响。
  - 但扩散修复的真实输出是**完全重生成（Fully Regenerated, FR）**图像：整幅图经过噪声采样与去噪过程，即使未编辑区域的语义内容看似不变，背景中的嵌入信号也已被破坏。
  - 因此现有方法在 FR 场景下严重失效，而这一问题此前**未被任何主动式定位工作系统研究过**。
- **整体含义**：本文首次系统评估 FR 设定下的主动式篡改定位，并提出 APT，使定位信号兼具"对背景重生成鲁棒"与"对前景合成脆弱"的**半脆弱（semi-fragile）**双重属性。

## 2. 方法论

### 2.1 核心思想
- 在 **VAE 隐空间**中优化一个可学习扰动 δ，将每个空间位置的特征向量对齐到一个预定义的**固定锚点方向** a。
- 前景与背景的对齐差异构成定位线索：
  - **背景**：修复过程大量依赖原始隐表示，锚点对齐得以保留 → 余弦相似度高。
  - **前景**：扩散模型从自然图像分布采样生成，锚点从单位超球面随机采样，统计上几乎不会对齐 → 余弦相似度低。

### 2.2 关键技术细节
- **隐空间嵌入**：原始图像经 VAE 编码得 z，加入扰动得 ˜z = z + δ，解码得 ˜x_perturb；再由图像编码器（DINOv3-ConvNeXt-Small，取 Layer 1，d=192）提取稠密特征图 F，逐位置特征向量记为 f_ij。
- **锚点构造**：锚点 a_ij 从 Rademacher 分布采样并归一化（取值 ±1/√d），近似单位超球面均匀分布；干净图像特征与锚点的余弦相似度统计上接近 0。
- **对齐度量**：s_ij = f_ijᵀ a_ij / (‖f_ij‖‖a_ij‖)，通过 **hinge 损失** 强制所有位置 s_ij ≥ τ（目标超锥 C），τ=0.1。
- **难负样本挖掘损失（L_hard）**：只对 hinge 损失最大的 top-K（K = ρ·H′W′，ρ=0.1）空间向量施加惩罚，解决编码器特征在超球面上分布不均导致的局部对齐不足问题。
- **噪声扰动分支**：对扰动隐变量 ˜z 施加随机二值矩形掩码，在掩码区域注入高斯噪声 ν ~ N(0, σ²)，σ ~ U(0, 0.25)，解码后同样施加 L_hinge 与 L_hard，以提升对 VAE 失真与背景重生成的鲁棒性。
- **总目标函数**：L_total = Σ_{ˆx∈{˜x_perturb, ˜x_noisy}} [L_hinge(ˆx) + L_hard(ˆx)] + λ_p·L_PSNR + λ_l·L_LPIPS（λ_p=0.1，λ_l=0.05）；最终像素域扰动以 ℓ∞ 范数裁剪（ε_δ = 16/255）。

### 2.3 验证阶段（定位）
- 输入测试图 → 提取特征图 → 逐向量余弦相似度图 s′ → 平均池化平滑。
- **两种检测器**：
  - **APT（无训练预测）**：m′ = σ(T · Upsample(s′))，温度 T=5.0，阈值 0.5 二值化。
  - **APT\*（浅层掩码解码器）**：轻量两级上采样（×2、×4）+ Conv-LayerNorm-ReLU，用 BCE + Dice 联合损失训练。由于无法构造大规模"受保护—被篡改"配对数据，改用**仅基于干净图像的合成相似度图**训练：在背景区域加对齐增益 ∆_bg ~ U(0.3τ, 0.9τ)，在前景区域施加对齐塌缩 ∆_fg ~ U(0.7τ, 1.1τ)，并加 η ~ N(0, 0.03²) 噪声。

### 2.4 算法流程（文字描述）
1. 对输入图像 x 做 VAE 编码得 z，初始化 δ=0；
2. 迭代（150 步，Adam，lr=1.0）：采样随机矩形掩码、噪声尺度与高斯噪声 → 构造 ˜z 与 ˜z_noisy → 解码得两幅扰动图 → 计算 hinge 与 hard 损失及感知损失 → 更新 δ；
3. 最终将像素域扰动裁剪到 ε_δ 预算内，输出受保护图像 ˜x。

## 6. 主要结论与发现

- **FR 设定**：APT\* 达到 **IoU 0.92 / AUC 0.97**，超过最强基线 WAM（IoU 0.84）；StableGuard 与 OmniGuard 的 AUC 塌缩至 **≈0.5（近随机）**。
- **SP 设定**：所有方法接近完美；APT/APT\* 保持 AUC 0.99、IoU 0.94–0.95，与 SOTA 相当，但未显式优化拼接边界，存在轻微边界误差。
- **跨模型迁移**：APT\* 在 4 种修复模型上平均 IoU 0.93；在 5 种不同 VAE / 架构（含流匹配模型）上 AUC ≥ 0.97、IoU ≥ 0.91，说明不依赖特定 VAE。
- **鲁棒性**：面对未见过的颜色抖动、模糊、JPEG 压缩，FR 下平均 IoU 0.90，SP 下 AUC 保持在 0.96 以上；StableGuard 在 SP 下平均 AUC 仅 0.80。
- **机理验证**：修复后前景区域余弦相似度均值 µ=-0.016，接近干净图像（µ=-0.062）；背景区域 µ=0.100，接近受保护图像（µ=0.107），证实"前景失配、背景保留"的对齐差异。
- **特征层选择**：Layer 1 在鲁棒性与空间粒度间取得最佳平衡（前景 µ=0.124 vs 背景 µ=0.265，双峰分离最明显）；Layer 0 高频扰动难以通过 VAE 瓶颈，Layer 2–3 感受野过大导致前景与背景纠缠。

## 7. 优点

- **问题新颖且实用**：首次系统定义并研究 FR 设定下的主动式篡改定位，贴合扩散修复的真实使用方式。
- **方法设计巧妙**：利用"锚点随机采样 → 生成模型天然偏离"的统计特性，无需对抗训练即可获得天然的前景—背景可分性；隐空间嵌入同时兼顾 VAE 鲁棒性与感知质量。
- **信号稠密且空间对应**：逐向量（vector-wise）对齐替代全局嵌入，天然支持像素级定位，避免全局信号缺乏空间对应的问题。
- **训练数据需求低**：浅层解码器仅用干净图像合成相似度图训练，无需真实的"受保护—被篡改"配对数据，工程可行性强。
- **验证全面**：跨 4+5 种修复模型 / VAE、两种篡改设定、多种损坏、消融与机理分析，且保持固定阈值即可同时适用于 SP 与 FR，实用性强。
- **安全设计**：锚点作为服务端密钥，检测器可作为黑盒 API，防止攻击者提取锚点。

## 8. 不足与局限

- **copy-move 场景失效**：若攻击者在同一张受保护图像内部进行复制—移动伪造，复制区域仍保留锚点对齐，缺乏对齐差异，可能导致**漏检（假阴性）**。
- **滥用风险**：恶意者可对已篡改图像施加 APT 扰动，使验证系统将其误认为"完好原图"；作者建议未来将主动防御前移至拍摄硬件端。
- **算力信息不完整**：仅报告单卡 4090 与单图耗时，未说明 GPU 数量、总训练开销与解码器训练成本。
- **实验覆盖局限**：主实验仅在 COCO 100 张（扩展 500 张）上进行，未涉及其他数据集、真实社交媒体图像或视频场景；掩码生成方式较为受控，未考虑自适应/对抗性攻击。
- **基线公平性存疑**：WAM、OmniGuard、StableGuard 并非为 FR 设计，其在 FR 下的失败虽反映现实，但直接对比可能未充分挖掘其适配潜力。
- **方法本身约束**：依赖固定的 SD-VAE 优化扰动，跨 VAE 迁移虽表现良好但仍是经验性结论；锚点对齐强度与感知质量、定位精度之间存在需要人工调参的权衡（τ、ε_δ、步数）。
- **假设前提**：方法成立依赖"背景重建会保留原始隐表示"这一扩散修复的普遍行为，若未来修复模型架构改变（如完全不依赖原图隐表示），信号保留性可能不成立。
