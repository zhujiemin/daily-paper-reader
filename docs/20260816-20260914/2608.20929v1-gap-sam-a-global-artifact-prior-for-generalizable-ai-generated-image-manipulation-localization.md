## 摘要
AI 生成图像篡改定位旨在识别被编辑的像素，但其 OOD 性能落后于图像级检测，部分原因是像素级监督将取证证据与数据集特定的掩码几何形状和语义边界纠缠在一起。将图像级分布对齐扩展到定位任务，我们构建了 COCO-ControlNet，使用源图像的 Canny 边缘和深度图来对齐语义与几何，从而提升了多种定位器的 OOD 性能。然而，更严格的掩码-VAE 重建对齐（Mask-VAE）表现不如 COCO-ControlNet，表明 VAE 重建伪影难以迁移到局部扩散修复伪影。我们还发现了“边界黏附”现象，即微调后的分割模型会将预测吸附到语义物体轮廓上，而不是真实的篡改边界。这些发现促使我们提出 GAP-SAM，它将图像及其冻结 VAE 重建编码为一个全局伪影 token，并在像素解码之前通过零门控 FiLM 将其注入 SAM3 的特征金字塔。在不预先指定空间区域的情况下，该 token 调制密集解码，以在抑制语义边界捷径的同时保持定位性能。在六个数据集上，GAP-SAM 平均达到 79.8 Pixel-F1，比最强先前方法高出 12.6 个点。在测试的每一种 JPEG 压缩、高斯模糊和缩放严重程度下，它也表现最佳。

## Abstract
AI-generated image manipulation localization identifies edited pixels, but its OOD performance lags behind image-level detection partly because pixel supervision entangles forensic evidence with dataset-specific mask geometry and semantic boundaries. Extending image-level distribution alignment to localization, we construct COCO-ControlNet with source-image Canny edges and depth maps to align semantics and geometry, improving OOD performance across multiple localizers. Yet tighter Mask-VAE Reconstruction Alignment (Mask-VAE) underperforms COCO-ControlNet, showing that VAE reconstruction artifacts transfer poorly to local diffusion-inpainting artifacts. We also identify \emph{boundary adhesion}, where fine-tuned segmentation models snap predictions to semantic object contours rather than true manipulation boundaries. These findings motivate GAP-SAM, which encodes an image and its frozen VAE reconstruction into a global artifact token and injects it into SAM3's feature pyramid via zero-gated FiLM before pixel decoding. Without prescribing a spatial region, this token modulates dense decoding to preserve localization while suppressing semantic-boundary shortcuts. Across six datasets, GAP-SAM averages 79.8 Pixel-F1, outperforming the strongest prior method by 12.6 points. It also performs best at every tested severity of JPEG compression, Gaussian blur, and resizing.

## 2. 方法论

### 2.1 数据层面的对齐设计：COCO-ControlNet

- 沿用 COCO-Inpaint 的数据构造流程与协议，以 **FLUX.1 [dev]** 为基座生成模型。
- 引入 **Canny 边缘**与**深度图**作为 ControlNet 结构条件，约束场景结构，减少生成不稳定与可见伪影。
- 掩码来源包括**基于标注**与**随机生成**两类（随机掩码可部分缓解语义边界捷径）；生成模式包括**掩码内修复（inpainting）**与**全图生成（full-image）**。
- 规模：约 **551K 训练样本**、**23K 验证样本**。

### 2.2 对照策略：Mask-VAE（作为反例）

- 用真实图像的 **VAE 重建结果**替换其掩码区域，构造“局部重建伪造样本”，实现像素级极紧对齐。
- 结论：在相同 COCO 源图与掩码下，Mask-VAE 在 CoDE、MaskCLIP 上的所有指标均**低于** COCO-ControlNet（表 1）。
- 原因解释：**空间支撑不匹配**（VAE 重建是全局解码痕迹，Mask-VAE 只是把这些全局痕迹裁剪进掩码，未适配边界与上下文）＋**伪影形成机制不匹配**（真实局部扩散修复的伪影依赖去噪轨迹、上下文、噪声调度、掩码边界与提示，VAE 编码-解码无法复现）。

### 2.3 GAP-SAM 核心方法

**整体流程（三个组件）**：

1. **全局伪影先验（Global Artifact Prior）**
   - 双分支编码：输入图像 $x$ 经 **LoRA 自适应 SAM3 编码器**得到观测金字塔 $F_o$；其冻结 VAE 重建 $R(x)$ 经**冻结 SAM3 编码器**得到 $F_r$（冻结以解耦先验提取与定位学习）。
   - 取两者**最终层**特征 $F_L^o, F_L^r$（256 维），分别做 **GAP + 分支特定 LayerNorm** 得到 $h_o, h_r$。
   - 拼接后经两层线性（中间 GELU + LayerNorm，512 → 256）得到 **256 维全局伪影先验 token $t_{art}$**。
   - 关键点：**先池化后融合**，显式去除空间坐标，使 $t_{art}$ 表达“重建相关伪影证据”而非“定位提议”；学习式融合（而非固定特征差分）保留两个视角的独立状态并建模其非对称关系。

2. **FPN 掩码解码（零门控 FiLM 注入）**
   - 将 $t_{art}$ 投影为每个 FPN 层级的通道级 **scale $\gamma_f$ 与 bias $\beta_f$**，对特征做特征级线性调制：$\tilde F_l^o = F_l^o \odot (1 + \alpha_f \gamma_f) + \alpha_f \beta_f$。
   - **门控标量 $\alpha_f$ 零初始化**，训练初始为恒等变换，逐步学习先验强度，避免破坏预训练表征。
   - **注入位置**：Mask Decoder 入口、Pixel Decoder 之前，使调制同时传播到 DETR 的 object queries（交叉注意力）与密集像素嵌入，最终由 Query Mask Predictor 输出掩码 $\hat M$；SAM3 原生解码结构不做改动。
   - 因调制在空间上广播，提供的是**取证上下文而非重建派生的区域/边界**。

3. **学习目标**
   - 定位损失：沿用 SAM3 官方微调配置 $L_{SAM3}$。
   - **伪影分类器**：共享分类头 $c(\cdot)$ 作用于 $h_o, h_r$；在 real-only 设定下，真实原图标为 0、其 VAE 重建标为 1，损失为两项 BCE 的均值：$L_{art} = \frac{1}{2|B_{real}|}\sum[\text{BCE}(\ell_{o,i},0) + \text{BCE}(\ell_{r,i},1)]$。
   - 总损失：$L = L_{SAM3} + \lambda_{art} L_{art}$，$\lambda_{art}=1.0$。
   - 该分类器只作用于全局池化描述子，**不引入任何掩码/边界/空间监督**，仅把配对特征空间锚定到“真实 vs 重建”的生成轴上。

### 2.4 训练细节

- SAM3 LoRA：rank 8、scaling factor 16、dropout 0；其余遵循 SAM3 官方配方。
- 优化：AdamW，**3 个 epoch**，有效 batch size 32，学习率 $2\times10^{-4}$，weight decay 0.05。
- 重建所用 VAE 来自 **Stable Diffusion 2.1**。

## 6. 主要结论与发现

- **发现 1**：篡改定位同样受益于分布对齐——7 个基线在 COCO-ControlNet 上重训后，平均 OOD Pixel-F1 **全部高于**官方权重。
- **发现 2**：**对齐并非越紧越好**。Mask-VAE 在像素上更贴近真实图像，却在所有报告列上劣于 COCO-ControlNet，说明当伪影形成机制与空间支撑与目标不一致时，最大化像素相似度无法带来最优泛化。
- **发现 3**：微调分割模型存在**边界黏附**——预测会沿人物、家具、道路设施等语义轮廓扩张/收缩，而非跟随真实篡改掩码。
- **主要结果**：GAP-SAM 在六个数据集上平均 **Pixel-F1 79.8、IoU 69.3**，分别超过各指标最强先前方法 **12.6 F1** 与 **16.2 IoU**；在 COCO-CN（98.3/96.7）、OpenSDID（90.5/82.7）、SID-Set（92.7/86.3）、AutoSplice（78.3/64.4）、UltraEdit（49.8/33.2）、DiffSeg30K（69.0/52.7）上均取得最佳 F1 与 IoU。
- **鲁棒性**

- **鲁棒性**：在 JPEG 压缩、高斯模糊、下采样缩放三类常见后处理失真下，GAP-SAM 随失真强度增大时的性能衰减幅度小于各基线，在中等与强失真区间仍维持领先。这一现象与方法的假设一致：全局先验分支依赖的是**重建相关的分布级证据**，而非精确的边界纹理或高频细节，因此对会破坏细粒度空间线索的后处理更具耐受性。相对地，依赖局部纹理/噪声一致性的传统取证定位器在强 JPEG 与强模糊下退化更快。

- **发现 4（机制层面的推断）**：由于 $t_{art}$ 在注入前已通过 GAP 去除了空间坐标，且门控 $\alpha_f$ 从零初始化逐步学习，模型无法直接把先验当作"区域提议"使用；消融中"原图-only 先验"弱于"原图+重建配对先验"，说明增益确实来自 VAE 重建所刻画的生成轴证据，而非仅仅增加了参数量或第二个编码分支。

## 7. 局限与可讨论之处

- **对齐"紧度"缺乏理论刻画**：论文只提供了 Mask-VAE 这一个反例来论证"过紧对齐有害"，但没有给出判断某种对齐是否可迁移的先验准则（例如空间支撑匹配度、伪影形成机制相似度的可操作度量），因此该结论目前是经验性的、难以外推指导新数据集构造。
- **边界黏附缺量化**：仅有定性可视化（图 4），未设计边界感知的评价协议（如边界带 F1、trimap 评估、语义轮廓一致性指标），也未统计黏附发生的频率与幅度。
- **对两处外部依赖较重**：全局先验依赖 SAM3 编码器与 Stable Diffusion 2.1 的 VAE，训练时需对每张图额外做一次重建前向；论文未报告由此带来的额外显存/时间开销，也未讨论 VAE 版本更换、SAM3 权重更新对结果的敏感性。
- **先验表示的信息瓶颈**：全局先验被压缩为单个 256 维 token，对同时存在多块、多类型篡改的图像，可能难以区分不同区域各自的证据；论文未做多 token / 区域化先验的对照。
- **评测覆盖的偏斜**：5 个 OOD 测试集均以扩散生成或扩散编辑为主，对传统拼接、复制-移动（copy-move）、重压缩等非生成式篡改的泛化未做验证，"通用篡改定位"的结论范围应限定在生成式编辑。
- **统计与敏感性**：未报告多随机种子方差、置信区间或显著性检验；$\lambda_{art}$、LoRA rank、门控初始化方式、GAP 前的层选择等关键超参均无敏感性曲线。

## 8. 总体评价与启示

- **核心贡献偏概念性**：论文的价值主要不在于某个新模块的堆叠，而在于把"像素级监督会引入非因果捷径、进而损害 OOD"这一诊断，转化为"用无空间坐标的全局取证先验去调制密集解码"的解法，思路清晰且与图像级检测的分布对齐经验形成呼应。
- **反例比正例更有信息量**：Mask-VAE 的失败与边界黏附现象，为"对齐紧度存在最优区间"这一开放问题提供了实证锚点，也为后续工作指明了方向——对齐应同时匹配**空间支撑**与**伪影形成机制**，而非单纯追求像素相似度。
- **工程可复用性较好**：先池化后融合、零门控 FiLM 注入、以及把分类头只作用于全局描述子的做法，都是低风险、易插拔的设计，原则上可迁移到其他"密集预测 + 取证/异常检测"任务骨干上。
- **仍需补强之处**：理论解释偏直觉、边界黏附缺量化诊断、算力与方差信息不透明，这三点会同时影响方法的可解释性与可复现性评估；若后续能给出对齐可迁移性的可操作判据，本文提出的原则将从"经验规律"上升为"设计准则"。
