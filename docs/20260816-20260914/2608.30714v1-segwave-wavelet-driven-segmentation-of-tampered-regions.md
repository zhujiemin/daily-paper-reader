## 摘要
验证图像真实性正变得日益困难，这给新闻、执法和政治等领域带来了严重风险。大多数现有取证方法依赖高层视觉伪影，并将帧检测视为简单的二分类任务。为解决这一问题，我们提出了 SegWave，一个联合利用空间域和频域线索进行图像篡改检测的混合框架。SegWave 将基于 Transformer 的架构与离散小波变换（DWT）相结合，以捕获表明存在篡改的局部化、多尺度频率不一致性。为了进一步提高定位效果，我们引入了自适应子带注意力模块（ASA），该模块动态突出信息丰富的高频小波分量。在多个基准数据集上的大量实验表明，SegWave 在具有挑战性的评估设置中始终优于最先进的篡改检测方法。

## Abstract
Verifying image authenticity is increasingly difficult, posing serious risks across journalism, law enforcement, and political domains. Most existing forensic methods rely on high-level visual artifacts and treat frame detection as a simple binary task. To address this, we propose SegWave, a hybrid framework that jointly leverages spatial and frequency-domain cues for image tampering detection. SegWave integrates a transformer-based architecture with the Discrete Wavelet Transform (DWT) to capture localized, multi-scale frequency inconsistencies indicative of manipulation. To further improve localization effectiveness, we introduce an Adaptive Sub-band Attention module (ASA) that dynamically highlights the informative high-frequency wavelet components. Extensive experiments on multiple benchmark datasets demonstrate that SegWave consistently outperforms state-of-the-art tampering detection methods in challenging evaluation settings.

- **现有方法的两大缺陷**：

## 2. 方法论

### 2.1 核心思想
SegWave（Segment any Manipulated Image using Wavelet Transforms）是一个**提示引导的混合 Transformer 框架**，把空间域特征与局部化小波频域线索统一起来，仅用**弱二元掩码监督**实现篡改区域分割与多来源划分。

### 2.2 关键技术流程（对应 Algorithm 1）
- **小波分解**：对输入图像做单级 Haar DWT，得到 LL（近似）、LH（水平）、HL（垂直）、HH（对角线）四个子带；**丢弃 LL，仅保留三个高频细节子带**（拼接边界、局部纹理不一致体现为高频不连续）。
- **自适应子带注意力（ASA）**：为 LH、HL、HH 计算动态注意力分数，突出最具判别力的高频信息、抑制结构性噪声，锐化篡改边界。
- **逆 DWT 重建**：将加权后的高频子带经逆变换重建出"增强图像"，使高频不一致性被显式放大。
- **双路 Patch Embedding 与特征融合**：原始图像与增强图像各自过 Patch Embedding 得到 $E_k$ 与 $\hat{E}_k$，经线性变换与调优后**相加融合**为统一表示，并**逐层注入 ViT 主干**，实现低级篡改线索与高级语义特征同时学习。
- **提示编码（Prompt Encoding）**：对真值掩码做**区域成对采样**——篡改区域标 1、真实区域标 0，各采样一个点，由 Prompt Encoder 编码到与图像嵌入兼容的空间，引导注意力关注相关区域，增强多来源感知。
- **掩码解码**：Transformer 掩码解码器融合图像与提示嵌入，借助可学习的 mask token 与 IoU token 输出分割掩码与置信度。
- **损失函数**：
  - 加权二元交叉熵 $L_{wBCE} = -w_+ y\log(\hat y) - w_-(1-y)\log(1-\hat y)$，用 $w_+$、$w_-$ 平衡正负样本；
  - 置信度均方误差 $L_{MSE} = \frac{1}{N}\sum_i(\hat c_i - c_i)^2$；
  - 总损失 $L_{total} = L_{wBCE} + \lambda L_{MSE}$，$\lambda = 0.1$（MSE 仅作轻量正则）。

### 2.3 推理与多来源划分
- 以 **16×16 网格均匀采样 256 个点提示**，分 **128 个一批**处理以规避显存溢出；图像嵌入只算一次，故多提示仍然高效。
- 对每个预测区域，将图像嵌入在区域 $R_{bin}(Y)$ 上平均得到**代表特征** $T_i$；对 $T_i$ 聚类为 $M$ 组（同源预测归为一组），每组选**置信度最高的掩码**作为代表；最终多来源用 softmax 融合、二元来源用平均融合。

### 2.4 消融变体
- **SegWave DCT**：用全局 DCT 替换 DWT。因全局 DCT 无方向性子带，ASA 模块被移除，其余管线保持一致，以隔离"变换选择"的影响。
- **SegWave w/o ASA**：保留 DWT 增强输入，但对三个高频子带**等权**处理。

## 3. 实验设计

- **训练数据**：CASIA 2.0 与 FantasticReality 的子集，各 2,000 张（合计约 4,000 张）。
- **评测数据集（均未参与训练）**：
  - RealisticTampering（220 张）
  - CocoGlide（512 张）
  - Columbia（180 张）
  - SafireMS-Expert（238 张，含 2/3/4 个来源区域，用于多来源划分）
- **评测指标**：
  - 二元定位：**permuted F1**，含 $F1_{fixed}$（阈值固定 0.5）与 $F1_{best}$（逐图最优阈值，上界）。
  - 多来源划分：**p-mIoU**（对标签维度取最优排列的 permuted mIoU）与 **p-ARI**（调整兰德指数，范围 −1~1）。
- **对比方法**：CAT-Net v2、TruFor、SAFIRE；消融为 SegWave DCT、SegWave w/o ASA。
- **主要结果**：

  - RealisticTampering：SegWave 0.36/0.51，**低于** TruFor 的 0.43/0.53；SegWave DCT 在该集上反超（0.40/0.49）。
  - 多来源（SafireMS-Expert）：2 源时 SegWave p-mIoU/p-ARI 为 **0.821/0.710**（SAFIRE 0.763/0.660）；3 源 0.648/0.641（SAFIRE 0.618/0.573）；4 源各方法趋同（0.422/0.577 vs 0.421/0.568）。

## 6. 主要结论与发现

- SegWave 在 CocoGlide 与 Columbia 上取得最优二元定位性能，在 SafireMS-Expert 的 2 源与 3 源设置上取得最佳 p-mIoU，2 源时优势最明显。
- **ASA 是增益关键**：在二元任务上收益有限（CocoGlide 0.67→0.69），但在多来源任务上显著（2 源 p-mIoU 0.695→0.821），说明当多个伪造来源共存时，其边界签名分布在不同方向子带上，**自适应重加权避免了信息稀释**。
- **DCT 与 DWT 互补**：全局 DCT 更擅长捕捉压缩诱导的周期性伪影（在疑似经历 JPEG 压缩的 RealisticTampering 上反超），方向性 DWT+ASA 更擅长捕捉拼接与生成式编辑的局部边界不一致。
- 随来源数增至 4，所有方法性能趋同，反映多源共置篡改的分离难度上升。
- 未来方向：统一 DCT 的压缩感知能力与小波的局部敏感性于单一模型。

## 7. 优点

- **问题定位精准**：指出"压缩伪影依赖 + 二元判决"是现有取证方法的双重瓶颈，并以"来源感知分割"作为更有实用价值的输出形式。
- **频域建模新颖且合理**：用 DWT 的**方向性、空间局部化**子带替代全局 FFT/DCT，天然适配 PNG 等无损格式，规避了 JPEG 依赖。
- **ASA 模块动机与证据自洽**：模块设计（重加权 LH/HL/HH）与"多源边界位于不同方向子带"的解释一致，且消融数据支持该假设。
- **弱监督下的强能力**：仅用二元掩码监督即实现多来源划分，避免了多源标注的高成本，具备实际可扩展性。
- **工程细节务实**：图像嵌入只计算一次、提示分批推理、单级 Haar + 轻量注意力，兼顾效果与开销。
- **学术诚实**：主动报告在 RealisticTampering 上不及 TruFor，并给出基于数据集压缩历史的合理解释，而非回避。

## 8. 不足与局限

- **性能并非全面领先**：在 RealisticTampering 的 $F1_{fixed}$ 上落后 TruFor 0.07，与摘要中"始终优于最先进方法"的表述存在张力。
- **多来源能力随来源数退化**：4 源设置下与 SAFIRE 几乎持平（0.422 vs 0.421 p-mIoU），优势消失。
- **训练规模小、泛化边界未知**：仅 4,000 张训练图，缺少跨数据集训练/测试与域迁移实验，"泛化性好"的结论证据有限。
- **鲁棒性验证缺失**：未评估有损重压缩、缩放、噪声、模糊、裁剪等常见后处理对定位的影响，而这类扰动恰恰是取证落地的主要障碍。
- **算力与效率信息空白**：无 GPU 型号/数量/训练时长、无推理时延与内存占用报告，无法评估实际部署可行性。
- **应用范围受限**：仅针对自然图像，未涉及文档/文本篡改场景；作者自述单级 Haar 适用性依赖"篡改区域相对较大"这一假设，对细碎篡改可能不足。
- **对比基线不完整**：未定量对比 MLLM 类可解释方法，也未与更新的频域/小波取证工作做横向比较；缺少置信区间与显著性检验。
- **潜在偏差风险**：对 RealisticTampering 的分析（"虽为 TIFF 但可能经过 JPEG 压缩"）为推测性解释，未提供量化验证；数据集与评测指标均沿用 SAFIRE 体系，可能继承其偏好。
