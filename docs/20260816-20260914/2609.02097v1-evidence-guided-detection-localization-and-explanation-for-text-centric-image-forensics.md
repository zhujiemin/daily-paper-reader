## 摘要
AIGC 的快速发展使以文本为中心的图像操纵日益易得，带来了新的取证挑战：不仅需要真实性检测，还需要空间定位与基于证据的解释。本文介绍了我们针对 ACM Multimedia 2026 GenText-Forensics Challenge 的解决方案。我们提出了一种证据引导的检测器-定位器-推理器系统，其中图像级检测器提供全局真实性先验，专用定位器提取篡改区域作为空间定位证据，基于 MLLM 的推理器则生成以该专家取证证据为基础的结构化取证报告。这些模块通过级联证据流相连：检测器控制后续定位与提示过程，定位器将篡改响应转换为定位框，推理器则经过训练，将检测器决策与定位证据综合为最终报告。作为方法的关键部分，我们引入迭代式难度感知挖掘以提高定位质量，并采用报告-掩码一致性后处理，使报告中的定位与预测掩码对齐。在官方隐藏测试集上，我们的系统取得了 0.638 的最终得分，并在挑战赛中排名第二，验证了所提出的证据引导系统的有效性。代码可在 https://github.com/peifengLiu42/ACMMM26-evidence-guided-detector-localizer-reasoner-system 获取。

## Abstract
The rapid progress of AIGC has made text-centric image manipulation increasingly accessible, creating new forensic challenges that require not only authenticity detection but also spatial grounding and evidence-based explanation. This paper presents our solution to the GenText-Forensics Challenge at ACM Multimedia 2026. We propose an evidence-guided detector-localizer-reasoner system, where an image-level detector provides a global authenticity prior, a dedicated localizer extracts tampered regions as spatial grounding evidence, and an MLLM-based reasoner generates structured forensic reports grounded in this expert forensic evidence. These modules are connected through a cascaded evidence flow: the detector gates the subsequent localization and prompting process, the localizer converts tamper responses into grounding boxes, and the reasoner is trained to synthesize the detector decision and localized evidence into the final report. As a key part of our method, we introduce iterative difficulty-aware mining to improve localization quality and apply report-mask consistency post-processing to align report grounding with predicted masks. On the official hidden test set, our system achieves a final score of 0.638 and ranks second in the challenge, validating the effectiveness of the proposed evidence-guided system. The code is available at https://github.com/peifengLiu42/ACMMM26-evidence-guided-detector-localizer-reasoner-system.

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：文档、收据等以文本为中心的图像是日常工作与司法场景中的关键证据。随着 AIGC 与高级编辑工具的普及，文本篡改可以保持原始版面布局、仅修改金额、时间戳等关键字段，**极小面积的改动即可完全颠覆证据有效性**。
- **任务升级**：传统图像取证多停留在"真/伪"二分类，而文本图像取证实际需要同时完成三项任务：
  - **真实性检测**（image-level detection）
  - **篡改区域定位**（pixel/region-level localization）
  - **基于证据的可解释分析报告生成**（evidence-based explanation）
- **挑战赛设定**：ACM Multimedia 2026 的 GenText-Forensics Challenge 基于 RealText-V2 数据集，将该任务统一为**结构化 Markdown 取证报告生成**，要求报告同时包含真伪判断、空间定位框和证据推理，评测综合检测、定位、解释与报告质量。
- **核心矛盾**：篡改证据具有**异构性**——
  - 图像级线索（全局统计偏差、长程相关性）→ 适合专家检测模型；
  - 区域级线索（边缘混叠、背景不连续、压缩不匹配）→ 需要精确定位；
  - 语义级异常（词/数字/字段被改导致逻辑矛盾）→ 需要 MLLM 语义推理。
  - 单一模型难以兼顾，专家模型缺乏语义推理，MLLM 又缺乏细粒度视觉感知。论文因此提出**专家模型 + MLLM 协作的证据引导框架**。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体架构：检测器—定位器—推理器级联

核心思想是构建一条**级联证据流**，让每一级模块的输出成为下一级的显式条件：

1. **检测器**输出图像级伪造概率 \(p_{det} = D(I)\)，以阈值 \(\tau_{det}\) 得到真伪标签 \(\hat{y}\)，作为全局真实性先验并**门控**后续流程；
2. 若判为伪造，**定位器**被激活，输出篡改概率热图 \(H = F(I)\)，经二值化、连通域过滤（面积阈值 \(\alpha\)）转为边界框集合 \(B\)；
3. **推理器**根据检测器标签与定位框构造**门控提示词**：
   - 判伪且有框 → 使用证据条件提示 \(P_{evi}(I, \hat{y}, B)\)；
   - 否则 → 使用真实性提示 \(P_{auth}(I, \hat{y})\)，不强制给出定位框；
4. 生成初始报告 \(R_0 = R(P)\)，再经**报告-掩码一致性后处理** \(\Psi_{rmc}\) 得到最终报告 \(R\)。

### 2.2 辅助定位监督的图像级检测器

- **骨干网络**：DINOv3 ViT-B/16，利用其 Transformer 表示捕获高分辨率文本图像的长程依赖，同时 patch token 保留空间信息。
- **特征融合**：将 CLS token 与 patch token 均值池化结果拼接 \(z_{img} = [z_{cls}; \frac{1}{N}\sum z_i]\)，兼顾全局摘要与分布式局部响应，经轻量分类头输出 \(p_{det}\)。
- **辅助定位头**：将 patch token 重塑为二维特征图，经轻量卷积解码器预测粗粒度热图 \(H_{coarse}\)。
- **联合损失**：\(\mathcal{L}_{det} = \lambda_1 \mathcal{L}_{BCE}(p_{det}, y) + \lambda_2 \mathcal{L}_{CE}(H_{coarse}, M) + \lambda_3 \mathcal{L}_{Dice}(H_{coarse}, M)\)，用像素级监督正则化检测器，迫使其保留篡改敏感的空间线索。

### 2.3 难度感知篡改定位（Difficulty-Aware Tampering Localization）

- **基础定位器**：DTD（面向文档篡改定位，兼顾视觉伪影与频域不一致），像素级 CE + Dice 损失。
- **动机**：高分辨率文本图像定位难度差异大，均匀采样会让已学会的简单样本占用大量更新，而小文本编辑、模糊边界、模型分歧区域等难样本被忽视。
- **迭代挖掘流程**：
  1. 先训练基线 DTD 作为第 0 轮状态，使"难样本"由**真实定位失败**定义而非人工假设；
  2. 每轮在训练集上运行当前 DTD，得到二值预测 \(D_i^{(t)}\)，并引入 ASCFormer 预测 \(A_i\) 与 SparseViT 预测 \(S_i\) 作为互补错误线索；
  3. 计算假阴性区 \(FN_i^{(t)} = M_i \setminus D_i^{(t)}\) 与假阳性区 \(FP_i^{(t)} = D_i^{(t)} \setminus M_i\)；
  4. **难度打分**（加权融合像素级错误、连通域漏检、大区域漏检、跨模型分歧）：
     \(s_i^{(t)} = 0.35 r_{fn} + 0.20 r_{miss} + 0.15 r_{large} + 0.15 \min(r_{fp}, 1) + 0.15 r_{dis}\)；
  5. 按规则将图像分为 **easy / medium / hard** 三组：严重定位失败（高难度分、低 F1、高 FN/FP、漏检连通域、漏检大区域）归为 hard，各项指标均好才归为 easy，其余为 medium；
  6. 微调时按固定组概率采样：\(\pi_{easy}=0.05, \pi_{medium}=0.35, \pi_{hard}=0.60\)；选中图像后裁 512×512 图块，hard 样本有 0.75 概率以挖掘出的错误区域为中心并加随机抖动；
  7. 每轮微调 30 个 epoch，选最优 checkpoint 进入下一轮，刷新难样本集，形成**闭环迭代** \(F_{dtd}^{(t+1)} = \text{FineTune}(F_{dtd}^{(t)}; \mathcal{M}^{(t)}, \mathcal{H}^{(t)})\)。

### 2.4 证据条件推理器的 SFT

- 从 RealText-V2 的图像-掩码-报告三元组构造 QA 风格 SFT 数据：掩码转为 [0, 999] 归一化边界框，真实样本分配零框，伪造样本在问题中嵌入可疑框。
- 问题 \(Q_i\) 包含图像 + 证据感知指令；答案 \(A_i\) 为挑战赛提供的参考报告（坐标同格式归一化）。
- 以标准自回归目标微调：\(\mathcal{L}_{sft} = -\sum_{i,t} \log p_\theta(a_{i,t} | Q_i, a_{i,<t})\)。

### 2.5 报告-掩码一致性后处理（RMC）

- 解析报告中的 `[GROUNDING]` 框，替换为定位掩码中重叠度最高的框；
- 若掩码中存在报告未覆盖的框，则作为补充异常条目追加，reason 字段标记为"专家模块补充"；
- 该步骤**不改变语义内容**，仅提升报告定位框与预测掩码的空间一致性。

## 6. 主要结论与发现

- **总体结论**：证据引导的检测器—定位器—推理器级联系统在官方隐藏测试集上取得 **0.638 分、排名第二**，验证了"专家取证证据条件化 MLLM 推理"这一路线的有效性。
- **证据引导的必要性**：显式专家证据对平衡的取证报告生成至关重要；去除检测器削弱真伪判断，去除定位器显著降低空间定位质量，说明全局与区域证据互补。
- **辅助定位损失有效**：仅做图像级分类不足以学到篡改敏感表示，加入粗掩码监督能同时提升检测与定位。
- **难度挖掘存在最优轮次**：第 1 轮即带来明显提升，第 2 轮最佳（IoU 较基线 +9.53），第 3 轮性能下降，说明**过度挖掘难样本会破坏分布平衡**，故最终采用第 2 轮模型。
- **RMC 后处理的作用边界**：显著提升定位指标，几乎不影响解释分数，是一种低成本的空间一致性对齐手段。

## 7. 优点

- **架构设计清晰且互补**：用"专家视觉模型负责感知、LLM 负责语义整合"的分工替代单一模型硬扛，规避了 MLLM 细粒度定位弱与专家模型无解释能力的双重短板。
- **级联证据流具有可解释性与可控性**：检测器门控定位与提示词构造，避免了直接 MLLM 推理常见的"无根据断言/幻觉"，使真伪判断、空间定位与文本分析三者对齐。
- **难度感知挖掘有针对性**：以真实定位失败（而非人工假设）定义难样本，融合 FN/FP、连通域漏检、大区域漏检与跨模型分歧，并配合难区域裁剪与分组加权采样，直击小编辑与模糊边界痛点；第 3 轮退化现象也做了诚实的分析与取舍。
- **RMC 后处理轻量有效**：仅对齐 grounding 框、补充缺失区域而不改动语义，兼顾一致性与报告原意。
- **工程完整度高**：从检测、定位、SFT 数据构造到后处理形成闭环，且代码已开源，便于复现与后续研究。

- **推理器与定位器解耦**：SFT 阶段推理器学习的是"给定掩码框 → 生成报告"，但推理阶段掩码来自定位器预测，二者分布存在 gap（exposure bias 的取证版本），论文未量化该 gap 对报告质量的影响。
- **未做失败案例的定性分析**：缺少可视化示例说明哪些类型的篡改（如颜色极接近、字体细微替换、整段文本重排）仍会失败，读者难以判断方法的能力边界。
- **效率与部署信息缺失**：级联系统需依次运行检测器（ViT-B/16 @ 896×1344）、定位器（DTD + 多轮挖掘）和 4B MLLM，推理成本显著高于单模型基线，但论文未报告延迟、吞吐或显存占用，实际可用性无法评估。
- **泛化性验证不足**：仅在 RealText-V2 上评测，未在跨数据集（如其他文档篡改数据集、不同语言/版式的票据）上验证，方法的通用性尚不明确。
- **消融中"w/o Detector / w/o Localizer"的替换策略未充分说明**：去除某模块后究竟是用真值替代、随机替代还是直接跳过该提示分支，会显著影响结论解读，论文对该细节交代不够充分。

## 9. 可借鉴之处与对未来工作的启示

- **"专家证据 → 条件化提示 → MLLM 推理"是一种通用范式**：不仅适用于文本图像取证，也可迁移到 Deepfake 检测、医学影像异常报告、遥感变化检测等"需要同时给出判断、定位与解释"的任务，核心是把专家模型的输出从"另一条并列的 pipeline"变成"LLM 的显式输入条件"。
- **辅助任务正则化主干表示**：在图像级分类器上挂一个粗粒度定位头，用像素监督反哺全局表示，是一种低成本提升检测器"篡改敏感性"的实用技巧。
- **用真实失败而非人工假设定义难样本**：难度感知挖掘的闭环设计（跑当前模型 → 统计 FN/FP 与跨模型分歧 → 重采样 → 微调）可推广到其他细粒度分割/定位任务，且论文展示的"第 3 轮退化"现象提醒研究者难样本挖掘存在分布偏移风险，需设置轮次上限或分布约束。
- **轻量后处理对齐多模态输出**：RMC 式的"解析结构化输出 → 与视觉预测对齐 → 补充缺失项"思路，可复用于任何需要 LLM 生成空间 grounding 的任务，用于抑制坐标幻觉。
- **诚实的评测态度**：在官方主观评分不稳定时，作者选择报告可复现的自算部分分数并说明与官方口径的差异，这种透明做法值得借鉴。

## 10. 总体评价

本文针对文本中心图像取证中"检测—定位—解释"三位一体的需求，提出了一条**证据引导的级联框架**：以带辅助定位监督的 DINOv3 检测器提供全局真实性先验，以难度感知迭代挖掘的 DTD 提供高精度篡改定位，再将二者输出作为显式条件注入 Qwen3-VL-4B 推理器，最后用报告-掩码一致性后处理对齐空间 grounding。方法在官方隐藏测试集上取得 0.638 分、排名第二，并在内部验证集上同时取得领先的检测与定位指标，验证了"专家感知 + LLM 语义整合"分工的有效性。其主要价值在于架构层面的清晰分工与可解释的证据流设计，而非单一模块的绝对性能突破；主要局限则在于验证集规模有限、官方评测不可细粒度归因、级联门控带来的误差传播风险，以及语义解释质量与定位精度之间的固有权衡。整体而言，这是一项工程完整、设计合理、结论诚实的工作，为多模态取证报告生成提供了可复现的基线范式。
