## 摘要
文本引导的扩散编辑引发虚假信息担忧，因此可靠的图像溯源至关重要。尽管水印通常用于此目的，但大多数方法携带固定 ID，无法解释改动了什么以及由哪个提示产生。此外，在开源白盒访问下，攻击者可以轻松定位并移除作为独立模块添加的水印。针对这一设定，我们提出 AngelFingerprint，一种新颖的水印框架，确保编辑可追溯性、可解释性和白盒隐蔽性。它将 LoRA 集成到扩散模型中，以将编辑提示的 CLIP 文本嵌入直接嵌入模型权重。随后，提取器仅从图像像素中恢复该嵌入。这种语义载荷解释了编辑，而权重集成设计使其即使在完全白盒访问下也难以检测和隔离。两项技术使这成为可能：保持编辑质量的速度对齐锚点，以及专门设计的频率滤波器，使水印不可感知但仍可恢复且鲁棒。在 MagicBrush 数据集上，我们的提取器在 200 路提示检索中达到 86% 的 top-1 准确率，而提示反演为 20%。

## Abstract
Text-guided diffusion editing raises disinformation concerns, making reliable image provenance essential. While watermarks are commonly used for this purpose, most methods carry a fixed ID that cannot explain what was changed and which prompt produced it. Furthermore, under open-source white-box access, attackers can easily locate and remove watermarks added as separate modules. Targeting this setting, we propose AngelFingerprint, a novel watermarking framework ensuring edit traceability, explainability, and white-box stealthiness. It integrates a LoRA into the diffusion model to embed the editing prompt's CLIP text embedding directly into the model's weights. An extractor then recovers this embedding from the image pixels alone. This semantic payload explains the edit, while the weight-integrated design makes it hard to detect and isolate even under full white-box access. Two techniques make this possible: a velocity-alignment anchor that preserves edit quality, and a specially designed frequency filter that keeps the watermark imperceptible yet recoverable and robust. On the MagicBrush dataset, our extractor achieves $86\%$ top-1 accuracy in a 200-way prompt retrieval, versus $20\%$ for prompt inversion.

# AngelFingerprint 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：文本引导的扩散编辑（如 SD3、UltraEdit）使图像编辑变成"一句话操作"，生成结果保留原始照片的大部分内容，因而比从零生成更具可信度，容易被用于伪造证据、虚假信息和未经同意的图像篡改。
- **溯源需求**：需要判断图像是否被 AI 编辑、以及"改了什么、由哪条指令产生"。
- **现有水印的两大不足**：
  - **载荷固定**：多数水印只嵌入固定 ID（如模型 ID、用户 ID、固定比特串），只能归属到模型，无法说明编辑内容与意图。
  - **模块可分离**：水印常由外部编码器或后处理模块注入，在开源白盒场景下攻击者可检查架构与代码，定位并移除该模块。
- **核心主张**：AI 编辑水印应同时满足三个属性——**可追溯性**（追溯来源素材）、**可解释性**（揭示编辑内容与潜在恶意意图）、**白盒隐蔽性**（架构与计算与原模型完全一致，难以检测或隔离）。
- **整体含义**：论文提出 AngelFingerprint，将编辑指令的 CLIP 文本嵌入通过 LoRA 直接写入扩散模型权重，由提取器仅从像素恢复该语义水印，首次同时满足上述三点。

## 2. 方法论

### 2.1 核心思想
- 不引入任何外部模块，仅在 DiT 注意力投影中插入 LoRA，把编辑提示的 **CLIP-L 文本嵌入**（768 维）作为水印载荷嵌入生成器权重。
- 提取器从生成图像中恢复该嵌入，从而实现"提示级"溯源与解释；权重级注入使模型在架构、计算、推理代码上与原始模型完全一致。
- 选择嵌入 CLIP 文本嵌入而非原始文本比特串的原因：SD3 的 DiT 只接收文本嵌入，注入原始文本需额外模块（违反隐蔽性）；且文本离散不可微，会破坏 LoRA 与提取器的联合训练。

### 2.2 训练目标（四项损失）
- **流匹配损失（Lfm）**：保留 SD3 原生 rectified-flow 目标，维持生成能力。对干净隐变量 z0、噪声 ε、插值 zt=(1−t)z0+tε，目标速度为 v⋆=ε−z0，最小化 LoRA 增强 DiT 预测与 v⋆ 的 L2 距离，权重 λfm=0.5。
- **嵌入恢复损失（Lembed）**：由两项组成：
  - **余弦对齐损失（Lcos）**：拉近恢复嵌入与自身目标嵌入的余弦相似度，权重 λcos=1.0。
  - **对称批内 InfoNCE 损失（Lnce）**：温度 κ=0.07，同时进行图像到文本、文本到图像两个方向的 B 路分类，迫使匹配对相似度高于不匹配对，直接优化检索边界。权重 λnce=1.0。
  - 仅用 Lcos 的问题：CLIP 文本嵌入处于窄锥内，提取器可能把所有载体映射到目标质心附近，使 sii≈sij，检索退化为随机；InfoNCE 通过负样本强制 sii > sij。
- **速度对齐保真锚点（Lref）**：防止 LoRA 为写入水印而漂移输出。关键设计是**四点对齐**——不只对齐引导速度 vlora_cfg 与 vvan_cfg（仅在某一引导尺度成立），而是分别对齐条件分支对 (vlora_c, vvan_c) 和无条件分支对 (vlora_u, vvan_u)，使两模型在任意引导尺度 w 下都相等。无条件分支权重更大（β>α），因其共享于所有提示、是引导外推的基础。权重 λref=3.0，(α,β)=(1.0,2.0)。
- **总目标**：L = λfm·Lfm + λembed·Lembed + λref·Lref。

### 2.3 频率滤波（关键技术）
- 在生成图像与提取器之间插入固定的 **DCT 带通滤波器 H**，只保留 8×8 块中 4≤i+j≤7 的 26/64 个中频系数，置零低频与高频；被屏蔽系数在前向被丢弃，也不接收梯度。
- 该设计一次解决四个问题：
  - **收敛性**：图像语义集中在低频，而流匹配与保真损失要求低频不变，梯度冲突导致训练不稳；滤除低频后水印被迫写入中频，优化更稳定。
  - **防止语义捷径**：目标提示嵌入与图像内容相关，提取器可能靠读图内容而非读水印来降低损失；屏蔽内容主导的低频带可消除该捷径。
  - **不可感知性**：低频主导外观，提取器不读低频，LoRA 也无动机写入，编辑外观保持不变。
  - **鲁棒性**：高频最先被压缩/重采样破坏，中频更稳定；DCT 掩码显式镜像 JPEG 算法，故对中高质量 JPEG 压缩"按构造"鲁棒。
- 滤波器与锚点互补：滤波器控制水印"住在哪里"，锚点控制输出"能漂多远"，两者作用于独立杠杆，使不可感知性与可恢复性同时提升而非权衡。

### 2.4 算法流程（文字说明）
1. 预训练 SD3 骨干、文本编码器、VAE 全部冻结；仅训练 LoRA 矩阵 θ 与提取器 Eϕ。
2. 给定源图 x 与编辑指令 y（CLIP-L 嵌入 τ(y)∈R768），LoRA 增强模型 Gθ 生成带水印图像 Gθ(x,y)。
3. 经固定频率滤波 H 后送入提取器，得到恢复嵌入 ê=Eϕ(H(Gθ(x,y)))。
4. 联合优化 θ 与 ϕ，最大化 ê 与 τ(y) 的相似度，同时用 Lref 锚定到无 LoRA 模型的速度预测。
5. 部署时 LoRA 合并进基础权重，模型对外表现为普通微调模型，无额外模块。

## 6. 主要结论与发现

- **提示恢复显著优于反演**：SD3-medium 上 cos_p=0.802、Top-1=0.860、MRR=0.917；UltraEdit 上 Top-1=0.655，说明方法不绑定单一骨干。
- **水印是恢复的唯一来源**：Δcos=+0.438、ΔT1=+0.860；无 LoRA 时提取器 Top-1=0.000，说明提取器读的是注入信号而非图像内容；基线方法 ΔT1 为负，说明它们读的是内容。
- **白盒隐蔽**：仅改权重，不改架构、计算与代码，无可隔离模块；提取器私有，攻击者难以定位水印。
- **视觉保真**：JPEG 中频掩码下 DreamSim 0.221、PSNR 22.91、SSIM 0.704、FID 132.1、KID 0.0032，接近无 LoRA 输出与真实图像分布；图 2 显示水印仅表现为难以察觉的网格状纹理。
- **鲁棒性**：对颜色抖动、高斯噪声、JPEG 压缩、裁剪、模糊鲁棒；**缩放（尤其裁剪+缩放）是主要威胁**，因重采样破坏 8×8 DCT 块同步。
- **权重级攻击**：int8 量化几乎无损（Top-1 0.860），int4 降至 0.505 但模型质量崩溃（KID 14.3→164.4）；继续微调 300 步后 Top-1 仍保持 0.575，远高于随机。
- **存在性检测**：提取器输出范数 ∥ê∥2 几乎完美分离水印图像与负样本，AUC=1.000；阈值 ∥ê∥2>12 时达到 100% TPR / 1% FPR。
- **开放集验证**：恢复嵌入具有语义意义，真实提示及其近义改写得分高，无关句低，验证者无需知道确切措辞即可识别编辑。

## 7. 优点

- **问题定义清晰**：将白盒、开放权重对手下的编辑水印形式化为可追溯、可解释、白盒隐蔽三要求，并指出前人只部分满足。
- **方法设计巧妙**：
  - 用 LoRA 权重级注入实现结构零差异，比外部模块更难定位与移除。
  - 以 CLIP 文本嵌入为语义载荷，使水印既能溯源又能解释编辑意图，且天然可微、适合联合训练。
  - 四点速度对齐比只对齐引导速度更严谨，保证任意 CFG 尺度下的保真。
  - DCT 中频带通滤波器一举解决收敛、捷径、不可感知与鲁棒四个问题，并与 JPEG 压缩机制对齐，鲁棒性"按构造"成立。
- **实验论证有说服力**：用 Δcos/ΔT1 严格隔离水印贡献；消融显示滤波器与锚点均不可或缺；存在性检测提供无需候选池的实用验证手段；开放集实验贴近真实部署。
- **实用性强**：水印模型可当作普通微调模型发布，验证流程支持手写假设、VLM 生成候选、指令语料三种池构建方式，并可结合嵌入反演直接还原文本。

## 8. 不足与局限

- **缩放鲁棒性差**：裁剪+缩放会破坏 DCT 块同步，Top-1 从 0.860 骤降至约 0.01，是该设计的结构性弱点；论文承认这是主要威胁。
- **缺少与语义水印的直接对比**：表 1 定位了 SWIFT、LatentSeal、Of-SemWat 等语义载荷方法，但实验未做数值对比，横向优势证据不足。
- **存在性检测的局限**（作者自述）：
  - 范数尺度在 SD3-medium 上测得，换骨干需重新校准阈值。
  - 负样本仅为同生成器 LoRA-off 图像与自然照片，未覆盖其它扩散模型输出或针对范数进行欺骗扰动的更强对抗负样本。
  - 每组 200 张不足以约束极端尾部，目标 FPR 低于 10⁻⁴ 需更大负样本集。
- **候选池规模有限**：主评估仅 200 条提示，真实场景池可能更大且分布不同；虽然作者称可扩展池并接受释义匹配，但未量化池规模增长对准确率的影响。
- **提取器为私有组件**：验证依赖持有提取器，若提取器泄露或被逆向，可能削弱安全性；论文未讨论提取器自身的保护。
- **数据集偏差风险**：MagicBrush 指令平均仅 6.5 词、以祈使动词开头，属于短指令分布；对更长、更复杂或多轮组合编辑的泛化能力未验证。
- **int4 量化下模型不可用**：虽然攻击者得到的水印模型质量崩溃，但这也意味着合法用户无法使用 int4 量化部署，属于应用限制。
- **未讨论对抗性水印去除**：如专门优化扰动以抹除中频信号、或训练去除 LoRA 的对抗方法，均未在威胁模型中覆盖。
