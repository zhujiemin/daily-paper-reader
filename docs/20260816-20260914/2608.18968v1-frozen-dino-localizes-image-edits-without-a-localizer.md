## 摘要
局部图像编辑可以改变照片的含义，同时让其中大部分内容保持真实，因此取证分析必须识别编辑发生在何处。我们表明，来自冻结 DINO 编码器的 patch 级扰动响应本身就是定位图。免训练的基于 patch-token 漂移的 AI 图像编辑定位（Training-free Localization of AI-image Edits from patch-token Drift, TRAIL）施加一次全局 Haar 扰动，并映射对应 patch token 之间的余弦漂移。在 80 张源不相交的 CocoGlide 测试图像上，TRAIL 达到 .903 的 patch AUROC，而掩码监督的 Detective SAM 为 .912；固定阈值 Dice 为 .619 对 .709，而 oracle 阈值将 TRAIL 提升至 .790。未经改动迁移到泊松图像插值后，TRAIL 达到 .855 AUROC，而对比值为 .864，表明该线索在没有生成器的情况下仍然存在。在十六个 DINO 编码器中，最佳 block 位于归一化深度 .80-.94。全局上下文很重要：AUROC 从全局的 .903 下降到局部画布内扰动的 .857，以及独立编码裁剪图像的 .735。因此，冻结 DINO 的 patch token 包含强烈的后层定位信号，其可见性取决于扰动和保留的上下文。代码：https://github.com/VishalJ99/trail-image-edit-localization。

## Abstract
Localized image edits can change a photograph's meaning while leaving most of it authentic, so forensic analysis must identify where an edit occurred. We show that patch-level perturbation responses from frozen DINO encoders are themselves localization maps. Training-free Localization of AI-image Edits from patch-token Drift (TRAIL) applies one global Haar perturbation and maps cosine drift between corresponding patch tokens. On 80 source-disjoint CocoGlide test images, TRAIL reaches .903 patch AUROC versus .912 for the mask-supervised Detective SAM; fixed-threshold Dice is .619 versus .709, while an oracle threshold raises TRAIL to .790. Transferred unchanged to Poisson image interpolation, TRAIL reaches .855 AUROC versus .864, showing that the cue persists without a generator. Across sixteen DINO encoders, the best block lies at normalized depth .80-.94. Global context matters: AUROC falls from .903 globally to .857 for local-in-canvas perturbations and .735 for independently encoded crops. Frozen DINO patch tokens therefore contain a strong late-layer localization signal whose visibility depends on the perturbation and preserved context. Code: https://github.com/VishalJ99/trail-image-edit-localization.

## 1. 核心问题与研究动机

- **背景**：生成式编辑工具可以只替换照片中的一小块区域，其余像素保持真实。图像级检测器只能回答"这张图被改过"，却无法回答"哪部分内容不再可信"；取证需要的是**空间定位**（edit localization）。
- **现有免训练检测的缺口**：RIGID、MINDER、WaRPAD 等方法利用冻结视觉编码器对扰动的敏感性做检测，但都把 patch 级响应**压缩成单个图像级分数**，丢弃了其中的空间结构。
- **已有定位方法的代价**：TruFor、Detective SAM 等直接从掩码监督学习定位，需要训练与标注；扩散重建类免训练方法（Zhang et al.）在推理时需要生成模型。
- **本文的核心问题**：一个**冻结的通用视觉编码器**（DINO 家族）在扰动下的响应里，本身已经含有多少定位能力？——即"不需要定位器，冻结特征能否定位编辑"。
- **整体含义**：作者主张被丢弃的 patch 级扰动响应本身就是一张定位图，并系统刻画了这一信号的深度位置、规模效应与上下文依赖。

## 2. 方法论（TRAIL）

- **核心思想**：Training-free Localization of AI-image Edits from patch-token Drift（TRAIL）——对原图施加一次**全局 Haar 扰动**，用冻结 DINO 编码器分别编码原图与扰动图，比较**对应 patch token 的余弦漂移**，直接读出空间响应。
- **关键步骤（文字化算法流程）**：
  1. 取冻结编码器第 ℓ 个 block 的 patch token fℓ,p(x)，排除 CLS 与 register token，不更新任何参数；
  2. 用二级 Haar 分解的重构细节分量 HF2(x) 做**全局**扰动：T(x) = x − α·HF2(x)，α = 0.2，变换确定且不使用编辑掩码；
  3. 计算每个 patch 的漂移分数：sℓ(p) = 1 − cos⟨fℓ,p(x), fℓ,p(T(x))⟩；
  4. 将分数重塑为 token 网格，过一个 reflect-padded 3×3 中值滤波，得到 TRAIL 图 M（**无任何学习式空间后处理**）。
- **配置选择**：主配置为 DINOv3 ViT-7B/16 @ 448×448，block 36，输出 28×28 图；block、滤波、阈值均在**测试访问前**基于 320 个开发源选定，阈值 τ = 0.0026。
- **诊断指标**：另报告逐图 oracle 阈值 τ*(x) = argmax_t Dice(1[M≥t], Y)，用真值掩码逐图选最佳切分点，仅作诊断、测试时不可用。
- **"免训练"的定义澄清**：指没有参数拟合到篡改标签或掩码；但 block、滤波与阈值仍依赖开发数据选择，因此是 **training-free 而非 validation-free**。
- **推理开销**：一次小波变换 + 两次冻结编码器前向。

## 6. 主要结论与发现

- **冻结 patch 漂移本身即可定位编辑**：CocoGlide 上 TRAIL 达 **.903 patch AUROC**，Detective SAM 为 .912，配对差 −.009（95% 区间 [−.049, .033] 跨零），即与掩码监督定位器在排序上**统计不可区分**。
- **排序强、二值化弱**：固定阈值 Dice 为 .619 vs .709（差 −.090，区间不含零）；但逐图 oracle 阈值把同一批 TRAIL 图提升到 **.790**（+0.171），说明差距主要来自**阈值标定**而非空间排序。oracle 阈值跨度 .00033–.01342，44/80 张图希望低于开发阈值、36 张希望高于，说明开发冻结的切分点在两个方向上都失配。
- **中值滤波贡献可观**：未滤波的原始漂移图 .843，滤波后 .903（+0.060）。
- **信号非平凡**：raw-pixel 控制仅 .641，aligned-real 控制 .697，F–R 增量 +.206 [.167, .246]，说明响应不能由像素扰动幅度或该区域的普通内容解释。
- **不依赖生成器**：配置原样迁移到 PII 达 **.855 AUROC**（对比 .864），FPI 达 .850（对比 .894），说明该线索在无生成模型的经典编辑上同样存在。
- **TGIF2 是主要边界条件**：语义掩码拼接上差距明显（.811 vs .904，Δ −.092；oracle Dice 差 −.178），且 aligned-real 控制在此高达 .743、F–R 增量降到 +.068，说明语义物体区域内的部分响应在编辑前就已存在；随机掩码组差距不显著（区间跨零）。
- **定位信号一致地出现在后层**：16 个编码器选出的最佳 block 全部位于**归一化深度 .80–.94**，无任何模型选择早/中层；且在 DINOv3 ViT-7B 上 block 35/36/37 表现近乎相同（.9029/.9037/.9032），非狭窄最优点。
- **规模效应体现在"编辑特异性"而非原始排序**：DINOv3 从 ViT-B 到 7B 原始 AUROC 变化很小（.885→.903），但 F–R 增量从 ViT-S 的 .089 单调升到 7B 的 .206；DINOv2+registers 与 DINOv2 类似；DINO 是例外（增量仅 .051/.043）。即容量更可靠地**把编辑相关漂移与真实源中已有漂移分开**，而非单纯抬高定位分。
- **全局上下文比扰动种类更重要**：对每种扰动，定位性能都从全局 → 画布内局部 → 独立编码裁剪依次下降（Haar：.903 → .857 → .735；噪声：.798 → .738 → .527；模糊：.830 → .646 → .610），且 Haar 在每种几何下都最好。作者指出这与 WaRPAD 的图像级检测结论相反（后者的裁剪构造有利于图像级检测，但不利于定位）。
- **Haar 剂量不敏感**：α ∈ {.05,.1,.2,.4} 给出 .900/.908/.904/.889，选中的 .2 落在宽平台内而非孤立最优。

## 7. 优点

- **问题切入巧妙**：把既有免训练检测方法"丢弃的空间响应"重新利用，几乎零额外机制（无学习头、无解码器、无分割模型）就得到定位图，思想简洁且可解释。
- **定义严谨**：明确区分"免训练"与"免验证"，主动披露 block/滤波/阈值是在开发掩码上选的，避免过度声称。
- **控制实验扎实**：raw-pixel 控制与 aligned-real 控制直接针对两种最可能的平凡解释，并引入 F–R 增量作为"编辑特异性"的量化指标，比单纯报 AUROC 更有说服力。
- **统计规范**：源级不相交划分、源级配对 bootstrap（10,000 次）、AUPRC 作为辅助指标、条件内先平均再汇总，避免样本量不均衡带来的偏乐观。
- **评价公平性意识强**：所有方法统一到 28×28 网格，并明确指出该

网格化处理对高分辨率方法可能偏保守，从而把自己的比较置于不利位置——这种自我设限提升了结论的可信度。

- **局限性披露主动**：作者在正文中明确写出"training-free ≠ validation-free"、TGIF2 上的因果混淆、失败样本分析不足等，而非留待审稿人指出。
- **诊断与实用指标分离**：固定阈值 Dice 与 oracle Dice 并报，既承认阈值标定的现实困难，又用 oracle Dice 证明空间图本身的质量上限，避免因单一操作点低估方法潜力。
- **负结果有信息量**：DINO 系列的例外、TGIF2 语义组的退化、局部/裁剪几何的下降都被如实报告并用于推导机制解释（全局上下文对定位的作用），而非被淡化。

- **阈值标定是最大短板**：固定操作点 Dice 仅 .619，与监督方法差 .090，且 oracle 阈值在开发阈值两侧均有分布（44 张希望更低、36 张希望更高），说明单一全局阈值难以适配不同图；作者未提出任何免真值的自适应阈值方案（如基于漂移分布的分位数、双峰检测），使方法的实际可用性受限。
- **计算成本高**：主配置需要两次 7B 编码器前向（原图 + 扰动图），对单张图片的取证场景尚可，但批量或边缘部署成本显著；论文未给出延迟/显存实测，也未探索更小编码器在成本—性能上的折中曲线（虽然报告了 ViT-B 等，但未系统给出精度—算力前沿）。
- **TGIF2 上的机制解释不够确定**：语义掩码组同时改变了掩码几何、语义类别与生成器，aligned-real 控制高达 .743 意味着语义物体内部本就有强漂移，但作者无法区分这是"语义先验"还是"生成器痕迹"导致，结论只能停留在"情形差异"。
- **失败模式分析薄弱**：仅定性提到 4 张失败图，且面积假设被同区间反例推翻（26 张中 22 张成功），没有进一步给出失败与编辑类型、纹理、掩码形状的相关性统计，读者难以预判方法何时失效。
- **对比方法覆盖有限**：监督参考只有 Detective SAM 一个，未与 TruFor、PSCC-Net、ObjectFormer 等其他定位器比较；免训练类也未与扩散重建法（Zhang et al.）直接对比，因此"与监督方法不可区分"的结论仅针对单一基线。
- **数据集偏窄**：主结果集中在 CocoGlide 与 TGIF2，前者是 GLIDE 修复、后者是拼接，二者都不能代表全图重生成、局部重绘（inpainting）等更主流的编辑形态；PII/FPI 虽属经典编辑但样本小（80/79）。
- **未检验跨域鲁棒性**：没有 JPEG 压缩、缩放、噪声等后处理下的定位表现，而真实取证场景几乎必然经过这些变换；论文也未讨论对抗性扰动或刻意规避该方法的可能性。
- **"免训练"叙事略强**：虽然参数不更新，但 block、滤波核、α、阈值均依赖开发掩码选定，严格说是一种"轻量开发集调参"，与完全不接触标注的免训练方法（如纯自监督异常检测）仍有距离，作者虽已澄清，但摘要与标题层面的表述仍可能被误读。

## 9. 总体评价与启示

- **贡献定位**：本文是一篇**诊断性/机制性**工作而非新 SOTA 方法论文。它的核心价值在于提出并验证一个反直觉命题——**冻结通用编码器的扰动响应里已经蕴含可用的空间定位信号**，且该信号与掩码监督定位器在排序上统计不可区分。这一发现对"是否必须为定位任务训练专用模型"提出了实质性挑战。
- **方法学启示**：
  1. **不要过早聚合**：patch 级响应被压缩成图像级分数会丢失空间结构，这一观察对所有基于扰动/敏感性的免训练检测方法都适用，可能启发对 RIGID、MINDER、WaRPAD 等已有方法的重新解读。
  2. **全局上下文对定位至关重要**：扰动几何的实验（全局 > 局部 > 裁剪）提示，图像级检测与空间定位对上下文的需求可能相反，设计定位方法时不能照搬检测的构造。
  3. **规模效应体现在"特异性"而非"灵敏度"**：ViT-S 到 7B 原始 AUROC 变化小，但 F–R 增量单调上升，说明大模型的价值在于区分"编辑引起的漂移"与"真实内容本身的漂移"，这一区分指标（F–R 增量）值得被后续工作采纳为标准报告项。
  4. **后层是定位信号所在**：16 个编码器一致选择归一化深度 .80–.94，且相邻 block 表现接近，提示该现象具有跨模型家族的普遍性，可作为设计免训练定位器的先验。
- **可扩展方向**：
  - 用漂移分布的统计量（分位数、双峰性、局部对比度）实现**免真值自适应阈值**，直接针对本文最大短板；
  - 将 TRAIL 图作为**弱监督信号**微调轻量头，检验"training-free 信号 + 少量训练"能否缩小与监督定位器的 Dice 差距；
  - 在 JPEG/缩放等后处理下测试鲁棒性，并探索多尺度或多扰动平均以提升稳定性；
  - 把该思路迁移到视频、文档、医学影像等域，检验"冻结编码器扰动漂移"是否为跨模态的通用定位线索。
- **适用读者**：图像取证、AI 生成内容检测、免训练表征学习方向的研究者；以及对"冻结大模型隐含能力探测"感兴趣的通用视觉研究者。
- **一句话总结**：本文证明，定位编辑所需的空间信息其实一直躺在被丢弃的 patch 级扰动响应里，冻结 DINO 在全局扰动下的 token 漂移就是一张可用的编辑定位图——排序能力已接近监督定位器，剩下的主要障碍是阈值标定与计算成本。
