## 摘要
为遵守近期要求生成内容可追溯的法规，现代水印采用了多比特事后水印方案。这些现代设计依赖于以深度神经网络实现的编码器-解码器对。这些模型通常被视为纯黑箱并进行端到端训练，水印信道的噪声则通过对含水印图像施加一组固定的几何变换和值度量变换来建模。我们认为，这种纯经验性方法会导致未经审视的设计缺陷，并缺乏理论性能保证。本文基于对编码器/解码器对输出的统计分析，提出了一种现代事后水印方案的通用理论模型。我们表明，这些深度神经网络隐式地定义了一个水印信道，该信道被建模为并行 AWGN 信道，消息采用 BPSK 调制进行传输。这强加了二进制字母表，极大地限制了这些水印系统的容量。另一个致命缺陷是它们缺乏密钥，使其本质上不安全。我们通过将水印安全性概念与在给定解码器输出统计模型下估计密钥的可能性相联系，使事后水印方案的水印安全性这一概念变得精确。综合这一理论分析的结果，我们提出了 SNW：一种新颖的事后水印系统，其在容量方面显著优于现有最先进的基线方法，同时提供强大的安全保障。值得注意的是，它不依赖于固定码本或二进制字母表，从而能够通过使用容量可达的纠错码达到接近香农容量的速率。

## Abstract
To comply with recent regulations requiring traceable generated content, modern watermarking has adopted multi-bit post-hoc watermarking schemes. These modern designs rest on an encoder-decoder pair implemented as deep neural networks. These models are usually treated as pure black-boxes trained end-to-end, with the noise of the watermarking channel modeled through a fixed set of geometric and valuemetric transforms applied to watermarked images. We argue that this purely empirical approach leads to unquestioned design flaws and a lack of theoretical performance guarantees. This work proposes a general theoretical model of modern post-hoc watermarking schemes grounded in a statistical analysis of the outputs of the encoder/decoder pair. We show that these deep neural networks implicitly define a watermarking channel modeled as parallel AWGN channels, with messages transmitted using BPSK modulation. This imposes a binary alphabet, greatly limiting the capacity of these watermarking systems. Another fatal flaw is their lack of a secret key, making them intrinsically insecure. We make this notion of watermarking security precise for post-hoc schemes by linking it to the possibility of estimating the secret key under a given statistical model of the decoder's output. By putting together the results from this theoretical analysis, we introduce SNW: a novel post-hoc watermarking system that significantly outperforms existing state-of-the-art baselines in terms of capacity while also providing strong security guarantees. Notably, it does not depend on a fixed codebook or binary alphabet, allowing it to reach a rate close to Shannon capacity through the use of capacity-achieving error-correcting codes.

## 2. 方法论

### 2.1 问题形式化与安全定义

- 沿用"多比特水印 = 在不可靠信道上可靠传输消息"的视角，给出归属追踪场景（Alice 的 API、Bob 提供密钥 k 与水印系统 W、每用户唯一 ID）。
- **威胁模型**：Kerckhoffs 原则下的**伪造（spoofing）攻击**——攻击者 Eve 观察 N 张含水印图像，目标是伪造 Camille 的身份（假定解码时无噪声）。擦除攻击只需把分析对象从无水印图像换成含水印图像。
- 严格区分两个概念：
  - **水印安全性（watermarking security）**：针对嵌入/判决机制 (e_k, d)，指密钥不可被估计，即未授权者不能访问"原始水印信道"。
  - **对抗鲁棒性（adversarial robustness）**：针对解码投影 f_d，指对像素级对抗扰动的稳定性。
- **定义 1（ηL-安全性）**：若攻击者获得 N 次独立观测后的期望伪造成功率不超过随机猜测成功率，则称系统 ηL-安全。文中指出，对抗鲁棒性需要用对抗机器学习工具单独处理，不在本文范围（附录 E 单独讨论）。

### 2.2 对现代水印信道的统计建模（核心贡献之一）

- 现代系统结构统一为：自编码器形式的嵌入（下采样 f_e → 瓶颈处嵌入 e → 上采样 f_e†）+ CNN 解码器 f_d + 线性头 d。
- 嵌入可写为 **w = f_e†(e(f_e(x), c))**，其中 e(·,c) = Mix(·, v(c))，v(c) 是**导向向量（steering vector）**（如 VideoSeal/PixelSeal 用 WAM 方法把第 i 比特映射到固定的 v_i⁻ 或 v_i⁺）；含水印图像按 PSNR 预算 γ 归一化后叠加。
- **关键经验发现**（10k 张 1024×1024 ImageNet 图像）：
  - 潜向量 z = f_d(x̃_wm) 近似多元高斯 N(μ_z, Σ_t)；
  - Σ_t **秩亏**，特征值呈"阶梯状"：M′ 个大幅值（鲁棒分量）、少量小幅值（脆性分量）、其余为零（冗余分量）；
  - 线性头的作用相当于**白化**：剔除冗余/脆性分量并去偏；
  - 软码字 c̃ 可建模为对角协方差高斯 N(ϱ_t c, σ_t I_M′)。
- **结论**：现代水印信道等价于 **M′ 条并行 AWGN 信道 + BPSK 调制**。
  - **命题 1**：C_{ϱ,σ} = 1 − h₂(1 − Φ(−|ϱ|σ⁻¹)) ≤ 1 bit/信道元素。即二进制字母表下 BPSK 虽最优，却把容量硬性限制在每维 1 bit。
  - 表 1 给出 PixelSeal/VideoSeal/TrustMark 的 (ϱ,σ) 与理论容量，并与经验容量吻合（验证模型可预测性）。
- **无密钥系统的安全性分析**：即使把线性头保密，Eve 只需用 L+1 个独立消息水印 L+1 张图，得到 L+1 个 (z, c) 对，即可解线性方程组 Wz + b = c 恢复 W、b，进而伪造任意消息。

### 2.3 SNW：安全神经水印（Secure Neural Watermarking）

- **密钥与嵌入（e_U, d_U）**：
  - 密钥集合 K 为所有 L×M′ 的半正交矩阵 U（UᵀU = I_M′）。
  - 导向向量构造为 **v = α·Uc/√M′ + √(1−α²)·(I_L − UUᵀ)q / ‖(I_L − UUᵀ)q‖₂**，即把能量在"秘密子空间"与"其正交补"之间按 α 分配；q ~ N(0, I_L)。
  - 判决机制 **d_U = Uᵀv = αc/√M′**（再取符号即退化为 BPSK）。由于 c 可为实值，可用嵌套格码等容量可达纠错码，不依赖固定码本或二进制字母表。
- **训练目标（联合优化 f_e, f_e†, f_d）**：
  **L = λ_align·L_align + λ_iso·L_iso + λ_qual·L_qual**
  - *对齐 L_align*：最大化提取表征与目标向量的余弦相似度（含池化前逐空间位置的 L_align^all 与池化后的 L_align^pool）。
  - *各向同性 L_iso*：惩罚同图不同码字、不同图不同码字、不同无水印图之间的内积相关（L_iso^same / L_iso^cross / L_iso^host），使潜空间在球面上均匀分布、协方差满秩。
  - *质量 L_qual*：PSNR 铰链约束 + LPIPS 感知损失（另有 JND 衰减）。
  - 额外引入**反伪造损失 L_spoof**：约束把某图的水印残差迁移到另一张图上时其表征与目标向量正交。
- **三阶段训练流程**：
  1. **Stage 1 找信号**：在无变换条件下用逐分量对齐 + 同图同构损失 + PSNR 损失训练，逐步加入变换增强；
  2. **Stage 2 信号池化**：转向池化表征对齐，加入三类各向同性损失与 LPIPS，提升感知质量；
  3. **Stage 3 反伪造微调**：加入 L_spoof，抑制残差迁移。

### 2.4 理论分析（容量与安全性）

- **容量（命题 2）**：将提取的导向向量建模为 ṽ = ρv + √(1−ρ²)·n（n 在 v 的正交超球面上均匀分布），单比特正确解码概率
  **p(ρ) = Φ( α·ρ/√(1−ρ²) · √(L/M′) )**，
  香农容量 **C_ρ = M′(1 − h₂(p(ρ)))**。α = 1（能量全部给水印信号）时鲁棒性最优。
- **PCA 密钥估计安全性（命题 3）**：攻击者用 N ≥ L 张图估计协方差 Σ_N，其总体特征值只有两个取值
  λ₁ = ρ²α²/M′ + (1−ρ²)/L（M′ 维），λ₂ = ρ²(1−α²)/(L−M′) + (1−ρ²)/L（L−M′ 维）；
  结合 Marchenko–Pastur 分布，若含水印协方差的经验特征值支撑集包含于无水印支撑集 S₀，则 PCA 无法估计任何密钥维度。所需观测数
  **N_L = η = max(1, (1−√λ₁·M′)² / [L(√λ₁ − 1/√L)²])**。
- **完美安全（命题 6）**：当 **α* = √(M′/L)** 时 λ₁ = λ₂，总体协方差严格各向同性，N → ∞，对 PCA 攻击完美安全；当 α = 1 且 L = M′ 时同样完美安全，且这正是容量最大的工作点——即"高效利用水印空间时，应把全部能量给水印信号；码字维度小于 L 时，反而必须浪费能量把信号'淹没'在随机噪声中"。
