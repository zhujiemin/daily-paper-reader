## 摘要
Tree-Ring 等语义水印方案会在扩散模型的初始噪声潜变量中隐藏一个可检测的模式。近期工作表明，这些水印不仅可被移除，还可被伪造：即使攻击者从未见过水印密钥，仍能生成被正版检测器接受的图像。我们使用作者发布的代码，在免费层双 T4 GPU 上复现了 Müller 等人针对 Stable Diffusion XL 上 Tree-Ring 的 Reprompt 伪造攻击，每块设备可用内存为 14.6 GB，单 GPU 内存显著低于原研究使用的 A40 硬件。攻击复现成功。在三个分支各六次试验中，我们检测到真实图像 6/6、干净图像 0/6、伪造图像 5/6，每次攻击耗时 325–332 秒。在受限条件下运行还得出三项进一步结果。发布的检测器计算非中心 χ² 统计量，但只返回其 CDF，因此我们恢复了被丢弃的统计量；我们的恢复结果与发布的检测器完全一致，并且由该统计量构建的两个自然评分在相同的十八个观测上将伪造组与干净零假设区分开，AUC 分别为 0.861 和 0.972。以半精度运行 SDXL 需要修补流水线中直接调用自编码器的地方，受控探测证实修补后的路径不会改变检测器统计量。最后，我们报告一个通过阅读检测器源码做出的预测，而随后的测量结果与之相矛盾。Notebook、固定版本的 fork 以及所有测量工件均随论文发布。

## Abstract
Semantic watermarking schemes such as Tree-Ring hide a detectable pattern in the initial noise latent of a diffusion model. Recent work shows these watermarks are not only removable but forgeable: an attacker who never sees the watermarking key can still produce images the genuine detector accepts. We reproduce the Reprompt forgery attack of Müller et al. against Tree-Ring on Stable Diffusion XL, using the authors' released code, on free-tier dual T4 GPUs with 14.6 GB of usable memory per device, substantially less per-GPU memory than the A40 hardware used in the original study. The attack reproduces. Over six trials of three arms we detect genuine images 6/6, clean images 0/6, and forged images 5/6, at 325-332 s per attack. Three further results came out of running it under constraint. The released detector computes a non-central $χ^2$ statistic and hands back only its CDF, so we recovered the discarded statistic; our recovery matches the released detector exactly, and two natural scores built from it separate the forged arm from the clean null at AUC 0.861 and 0.972 on the same eighteen observations. Running SDXL in half precision requires patching the pipeline's direct autoencoder calls, and a controlled probe confirms the patched path leaves the detector statistic unchanged. Finally, we report a prediction we made from reading the detector source that our measurements then contradicted. The notebook, the pinned fork and every measurement artifact are released with the paper.

# 论文总结：Forging Tree-Ring — 复现并插桩黑盒语义水印伪造

## 1. 核心问题与整体含义

- **背景**：文本到图像扩散模型已足以以假乱真，"图像是否机器生成"不再是纯学术问题。水印是主流溯源手段之一，其中**语义水印**（如 Tree-Ring）不在像素空间后处理，而是把信号编码进扩散模型的**初始噪声潜变量** $z_T$，使水印成为生成轨迹的内在属性，因而能抵抗压缩、裁剪、模糊等像素域攻击。
- **关键转折**：Müller 等人（CVPR 2025）证明 Tree-Ring 不仅可被**移除**，还可被**伪造**——攻击者从未见过水印密钥，仅凭一张水印参考图，在**代理模型**（proxy）中做 DDIM 反演，再用恢复的潜变量生成全新图像，正版检测器依然接受。
- **本文动机**：独立复现该 Reprompt 攻击，在**自己可控的受限硬件**上建立可验证基线，再在其上构建后续工作。作者指出复现本身就有价值：一项针对约 750 篇 ML 安全论文的纵向研究发现 60% 不提供代码、56% 的已有工件无法运行。
- **整体含义**：伪造方向比移除方向对溯源更致命（造成**假阳性**而非假阴性）。鲁棒性评估与溯源声明所依赖的性质**正交**——鲁棒不等于不可伪造。

## 2. 方法论

### 2.1 核心思想

- 攻击概念：环形模式能**跨模型**在 DDIM 反演中存活，因此攻击者可用一个从未持有密钥的代理模型 $u_A$ 反演水印图 $x^{(w)}$ 得到 $\hat{z}_T^{(w)}$，再在任意提示词下生成无关新图，目标检测器仍判为真。
- 本文额外工作：**检测器插桩**——恢复被丢弃的中间统计量，并加入**干净零假设臂（clean null arm）**作为经验对照。

### 2.2 关键技术细节

- **检测器原理（式 1）**：对恢复的掩码系数 $f$、密钥模式 $t$、标准差 $\sigma$：
  - $x = \sum_i \left(\frac{f_i - t_i}{\sigma}\right)^2$
  - $\lambda = \sum_i \frac{t_i^2}{\sigma^2}$
  - 返回 $p = F_{\chi'^2}(x; df, \lambda)$，当 $p < \tau$ 判为真；SDXL 在 1% 假阳性率下 $\tau = 0.0261$。
- **统计量恢复**：原检测器只返回 CDF 值 $p$，丢弃 $x, \lambda, df, \sigma$。作者按式 1 重实现并保留全部中间量（Listing 2），在每个观测上把恢复的 $x$ 重新推回同一 CDF 与原检测器比对，断言误差 $< 10^{-12}$。
- **两个候选分数**：原始差异 $-\!x$（越低越匹配）与调整形式 $\lambda - x$（用非中心参数校正，因 $\sigma$ 随图变化，二者**非单调相关**）。
- **半精度修补**：SDXL 自编码器配置 `force_upcast=True`，但发布代码在 `vae_encode` / `latents_to_imgs` 中**直接调用**自编码器，绕过 diffusers 的处理，fp16 下溢出导致检测返回 NaN。作者新增 `_vae_upcast` 辅助函数：保存 dtype → 若为 fp16 且 force_upcast 则提升到 fp32 → 调用后恢复。
- **测量流程（Algorithm 1）**：每轮试验对同一水印实例产出三个观测：
  - **genuine**：目标模型生成水印图并反演回来；
  - **clean**：同提示词从普通高斯噪声生成（经验零假设）；
  - **forged**：真实图在攻击模型中反演、在无关提示词下重生成，再交回目标检测器。
- **溯源与门控**：所有改动放在 fork 仓库中并按 commit hash 固定，notebook 执行 `git reset --hard` + `git clean -fd` 并断言工作树干净；每个会话开头序列化 commit hash、模型标识、dtype、库版本、依赖锁 SHA-256。用四道可行性门 G1（内存）、G2（耗时）、G3（统计量可恢复性）、G4（假设可分性）组织实验。

## 3. 实验设计

- **场景/模型配置**：
  - 目标模型：**Stable Diffusion XL base 1.0**，DDIM 调度器；
  - 攻击代理：**Stable Diffusion 2.1 base**（原仓库被撤回，使用同权重镜像）；
  - 生成与反演均为 512×512、50 步、guidance scale 7.5。
- **水印配置**：Tree-Ring 发布默认值——环形模式、圆形掩码、半径 10、通道 3、复数注入、`l1_complex` 测量，$df = 634$；阈值 $\tau = 0.0261008646426459$。
- **随机种子**：生成种子 $123+i$（试验 1–6 对应 123–128）；水印密钥 `w_seed` 固定为 999999，**所有 18 个观测共享同一密钥**。
- **Benchmark / 对照**：没有独立数据集或标准 benchmark，唯一对照是 Müller 等人原文报告的同模型配对结果（genuine 1.00、clean 0.01、forged 0.97）以及检测器阈值 $\tau$ 本身；干净臂充当经验零假设。
- **对比方法**：仅复现 **Reprompt**，未复现基于优化的 **Imprint** 变体（后者单次成本高约两个数量级，超出算力预算）。

## 4. 资源与算力

- **硬件**：免费层 notebook 服务的**双 NVIDIA T4**，每卡可用显存 **14.6 GB**；原研究使用 **A40（48 GB）**并分布到 8 卡。
- **不可用资源**：P100 因 `sm_60` 被 PyTorch 2.10 放弃支持而不可用；T4 不支持 bfloat16，故 **FLUX.1-dev** 无法运行。
- **显存实测（G1）**：攻击者 fp32 峰值 **5.57 GB**；目标 fp16 **7.36 GB**；目标 fp32 **13.68 GB**。三者单独都能放进单卡，fp16 为目标卡释放 **6.32 GB** 余量（从不足 1 GB 提升到约 7.2 GB）。
- **时间成本（G2）**：单次 Reprompt 攻击 **325–332 秒**（两次独立会话测得 332.0 s 与 324.8 s）；原文报告小模型约 30 秒、FLUX.1 单卡单批最多两分钟。
- **会话安排**：完整流水线在相隔 11 天的**两次独立会话**中从干净环境重建执行；所有统计量逐位复现，仅墙钟时间波动 2.2%。原文说明其分配为每周 30 GPU 小时专用，本文为共享环境。

## 5. 实验数量与充分性

- **实验规模**：6 轮试验 × 3 臂 = **18 个观测**，单密钥；加上一次半精度受控探针、一次独立会话重跑、以及一套事后统计再分析（bootstrap 置信区间、Mann-Whitney、Cohen's d）。
- **充分性评价**：
  - 足以确立"攻击可复现、统计量可恢复、半精度路径保持检测输出"这些**存在性结论**；
  - **不足以**做分布性论断——作者明确将 AUC 读作排序指标而非校准估计。
  - 样本量触及检验分辨率下限：$n=6$ 时双侧 Mann-Whitney 最小 $p = 0.0022$、精确配对 Wilcoxon 最小 $p = 0.0312$，达到下限只表示完全分离。
  - 三次比较未做校正，Bonferroni 校正后配对检验均不显著，非配对检验仅在 $\lambda - x$ 上存活。
- **公平性/客观性亮点**：
  - 观测按试验配对（第 $i$ 轮伪造图源自该轮真实图，干净图共享提示词），因此**非配对检验并非自然选择**，作者主动指出这一点；
  - 主动披露**一个被数据推翻的预测**（原以为 $p$ 值会在强真实检测上左删失为 0，实测 18 个观测中 0 次为 0，最小值 $5.45 \times 10^{-49}$）；
  - 主动披露第二个方法学瑕疵：半精度探针在补丁已合入 fork **之后**才运行，因此只验证了修补路径，并未独立定位原始故障。
- **覆盖不足**：仅一个水印密钥、仅 Reprompt 一种攻击、仅纯净图像（未经过再压缩/缩放/截图）、未与任何伪造检测基线比较、未测试 FLUX.1-dev 与 PixArt-Σ。

## 6. 主要结论与发现

- **攻击复现成功**：真实 6/6 检出、干净 0/6、伪造 **5/6**，伪造中位 $p = 2.30 \times 10^{-5}$，低于阈值三个数量级；干净臂均值 $p = 0.480$ 对原文 0.472，最直接地验证了检测器配置；直接调用发布入口也得出一致结果（真实 $p = 3.53\times10^{-33}$，伪造 $p = 3.13\times10^{-6}$）。
- **统计量可恢复且完全一致**：18 个观测的 $x$ 跨度 889.1–1802.2（$df=634$），与发布检测器的最大绝对差**恰为 0**，排除重实现误差作为后续结论的解释。
- **分数选择是建模决策**：同一批 18 个观测上，伪造臂对干净零假设的 AUC 在 $-\!x$ 下为 **0.861**，在 $\lambda - x$ 下为 **0.972**；真实臂两种分数均为 1.000。$\sigma$ 跨 31.75–42.59、$\lambda$ 跨 856.6–1541.4，两分数非单调相关，因此分数必须**事先固定**，事后挑选即为在测试集上选择。
- **伪造臂落在中间带**：伪造臂位于干净零假设与真实臂之间，唯一被漏检的伪造 $x = 1558.3$，落在干净区间 1483.7–1802.2 之内——不是擦边失败，而是在检测器实际使用的统计量上与未加水印图无法区分。
- **接口层面的发现（最受作者看重）**：检测器计算了 $x, \lambda, df, \sigma$ 却只返回 CDF 值，把可用于分析的证据在返回决策的那一刻丢弃；暴露这些中间量**零成本**。
- **被推翻的预测**：$p$ 值并未左删失为 0；恢复统计量的理由需改基于分数压缩/饱和（$\lambda - x$ 的区分度），而非数值下溢。
- **半精度修补有效但验证范围窄**：修补后 fp16 与 fp32 在同一图像上返回完全相同的 $p = 1.6648\times10^{-36}$；但这只说明修补路径保持检测输出，**不证明**原始溢出是想象出来的。

## 7. 优点

- **复现的工程严谨性**：以 commit hash 固定 fork、断言工作树干净、序列化依赖锁 SHA-256，会话元数据随工件发布，两次独立会话统计量逐位复现。
- **加入干净零假设臂**：没有经验零假设就无法说某个分数"是"什么证据，只能说是否越过阈值；这是测量设计上的关键增益。
- **统计量恢复 + 严格验证**：与官方检测器误差恰为 0，使后续分数比较不受重实现误差污染。
- **对分数选择的自我约束**：明确拒绝事后挑选分数
