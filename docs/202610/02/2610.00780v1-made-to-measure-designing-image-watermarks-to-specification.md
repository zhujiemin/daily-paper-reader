## 摘要
图像水印通过将可验证的身份信息嵌入图像来支持来源追溯与归属。然而，实际部署必须同时满足抗攻击性、假阳性率（FPR）、图像质量和延迟等方面的要求。现有水印方法对不同类别的变换具有鲁棒性，因此组合互补方法可以提供比任何单一水印更广泛的保护。这种组合具有挑战性，因为额外的片段会增加失真和解码成本，并且必须共享相同的 FPR 预算。因此，我们提出 **TAILOR**，一个以请求为条件的水印组合框架，包含三个阶段：（1）*离线表征* 以嵌入强度为自变量，测量片段恢复、失真和运行时的响应曲线；（2）*联合配置选择* 将这些曲线上的请求编码为 SMT 模型，并求解片段、强度、顺序和几何恢复的最低失真组合；（3）*在线校准* 在用户图像上验证所选配置，并细化未能迁移的预测。在涵盖五个场景和 20 种攻击设置的 7,321 个不同请求上的实验结果表明，**TAILOR** 实现了 **96.21%** 的场景平均请求满足率，平均 PSNR 为 **41.02 dB**，在鲁棒性上优于现有方法，同时始终获得更好的图像质量。代码见 [https://github.com/aaFrostnova/Tailor](https://github.com/aaFrostnova/Tailor)。

## Abstract
Image watermarking supports provenance and attribution by embedding verifiable identity information into images. Practical deployments, however, must jointly satisfy requirements for attack resistance, false-positive rate (FPR), image quality, and latency. Existing watermarking methods are robust to different classes of transformations, so combining complementary methods can provide broader protection than any single watermark. Such composition is challenging, as additional fragments increase distortion and decoding cost and must share the same FPR budget. Therefore, we propose **TAILOR**, a request-conditioned watermark composition framework with three stages: (1) *offline characterization* measures fragment recovery, distortion, and runtime as response curves over embedding strength; (2) *joint configuration selection* encodes the request as an SMT model over these curves and solves for the lowest-distortion composition of fragments, strengths, order, and geometric recovery; and (3) *live calibration* validates the selected configuration on the user's images and refines predictions that fail to transfer. Experimental results across 7,321 distinct requests spanning five scenarios and 20 attack settings show that **TAILOR** achieves **96.21%** scenario-averaged request satisfaction with a mean PSNR of **41.02 dB**, outperforming existing methods in robustness while achieving consistently better image quality. Code is available at [https://github.com/aaFrostnova/Tailor](https://github.com/aaFrostnova/Tailor).

## 2. 方法论

### 2.1 总体思想与问题形式化

- 部署请求记为 `u = (A_u, α, q, t)`：攻击集、FPR 预算、PSNR 下限、延迟上限。
- 配置记为 `c = (S, λ, π, φ)`：片段子集 S、各片段嵌入强度 λ、嵌入顺序 π、至多一个几何恢复阶段 φ。
- 目标：在满足全部请求约束的可行集中，求**预测失真最小**的配置（等价于最大化 PSNR）。
- 三阶段流程：
  1. **离线表征**（Offline Characterization）→ 构建性能数据库；
  2. **联合配置选择**（Joint Configuration Selection）→ SMT 求解；
  3. **在线校准**（Live Calibration）→ 在用户图像上实测验证，必要时修正后重解。

### 2.2 阶段一：离线表征

- **片段库**：VINE（残差尺度）、TrustMark（嵌入强度）、VideoSeal（混合尺度）；统一承载同一 100-bit 载荷（经各片段密钥派生的置换与符号掩码）。
- **测量内容**：每个片段在攻击 a 下的平均比特准确率 `b_f(λ_f, a)`、单独嵌入失真 `D_f(λ_f)`（MSE）、嵌入/解码延迟；以及组合效应：
  - `δ_{g→f}(λ_g, a)`：g 嵌在 f 之后对 f 恢复的损失；
  - `e_{fg}`：超出单独失真之和的成对额外失真。
- **连续强度建模**：用**分段线性（PWL）模型**在离散测量节点间插值（式 1），并可直接编码进 SMT（引入每段一个布尔变量，恰好激活一段，禁止外推）。
- **预测量**：
  - 恢复预测：`b̂_f(c,a) = b_f(λ_f,a) − Σ_{g: f≺π g} δ_{g→f}(λ_g,a)`（式 2）；
  - 失真预测（在 MSE 域建模，因 MSE 近似可加且约束保持线性）：`D(c) = Σ D_f + Σ e_{fg} + D_φ(c)`（式 3），PSNR 下限 `P(c) ≥ q` 等价于 `D(c) ≤ 255²·10^{−q/10}`；
  - 延迟 `L(c)`：各片段嵌入 + 解码开销 + 几何阶段开销；
  - 逐图接受率 `Γ_{f,a}(c)`：用存储的逐图分数估计超过验证阈值的图像比例（含等渗拟合）。
- **几何恢复阶段**（4 个，源自各片段几何失效模式）：
  - **Scale**（服务 VINE）：环形载荷，在 K ∈ {1.00, 0.75, 0.50} 多半径嵌入，解码枚举 133 个中心尺度（0.34–1.00，步长 0.005）；
  - **Tile**（服务 TrustMark）：2×2 网格重复整码，解码以 256px 窗口、32px 步长滑窗（81 个位置）；
  - **Resync**（服务所有片段）：附加 SyncSeal 模板，由预测角点恢复单应矩阵，另加 ±3°、±6° 倾斜，共 5 视图/片段；
  - **Angle**（服务所有片段）：从旋转填充楔形边界估计角度，回退到 10° 网格扫描，最多 65 视图/片段。
- **关键实证发现（表 4）**：VINE 的载荷是**边框环**（仅占 19% 面积却含 50.7% 残差能量），TrustMark 是**中心偏置的全局铺展**，VideoSeal 近似均匀——这解释了它们在几何攻击下的不同失效方式，也是几何阶段设计的依据。

### 2.3 阶段二：联合配置选择（SMT）

- **搜索空间**：15 个有序非空片段子集 × 兼容几何阶段 × 每个片段的连续强度。
- **FPR 约束（含联合界）**：
  - 配置暴露多条验证路径（单片段、融合、几何视图），设最大允许测试数 `T(c) = T_0(m) + 5mz_r + 133z_s + 81z_d + 65mz_a`（式 12，m = |S|，T_0(m) = 1 或 m+1）；
  - 零假设下匹配比特数服从 `Bin(100, 1/2)`，将 α 分摊到每个测试（α/T(c)），取最小整数匹配阈值 θ(c,α)，归一化为 `τ(c,α)`（式 14）；再经 union bound 保证配置级 FPR ≤ α（式 15）；
  - **验证路径越多，阈值越严格**——这是"组合必须共享 FPR 预算"的具体机制。
- **攻击覆盖**：用保守筛选裕度（均值精度裕度 η、接受率裕度 η_rate）做离线筛选，`Cov_a(c)` 要求每个请求攻击至少被一个选中片段覆盖（式 6）；裕度只用于离线筛选，在线校准使用原始 τ 与 ρ。
- **质量与延迟**：`P(c) ≥ q`、`L(c) ≤ t`。
- **优化流程**：以"是否存在 `Φ_u(c) ∧ D(c) < D_best − ε`"（式 8）反复调用 SMT 求解器（Z3），逐步改进最优解直至无改进，返回最低失真配置。

### 2.4 阶段三：在线校准

- **Live Check**：在用户图像上跑完整"编码 → 攻击 → 解码"管线，要求每个攻击下满足图像级接受率 ≥ ρ（ρ = 0.90）与平均恢复 ≥ τ(c,α)，且实测 PSNR、延迟达标（式 9）。
- **请求局部细化**：
  - 按预测质量顺序测试最多 **3 个不同离散结构**；
  - **均值恢复修正**：观测差距 g = b̄ − b̂，若 |g| ≥ 2·se 则用收缩因子 `σ₀²/(σ₀²+se²)` 加权（σ₀ = 0.023），且**只接受悲观方向**的修正（式 16），避免采样噪声制造虚假 SAT；
  - **接受率修正**：通过二分搜索将存储分数分布整体下移 [−0.4, 0]，使预测接受率匹配实测；
  - **模型更新**：修正作用于**整条响应曲线**（而非单点），避免求解器在同一乐观曲线上邻近强度重复失败；修正只写入请求局部副本，不污染共享数据库；随后重解一次，新候选仍须通过同样在线验证。
- **结果语义**：首个全部通过者为 `c_out`，判定 **SAT**；否则在候选预算内判定 **UNSAT**（"在编码模型与候选预算内未找到满足请求的配置"），语义诚实、不假装成功。

  - **PSNR-P**：在双方**共同接受**的请求上比较，剥离覆盖率影响，做到同请求同图像的可比性。
- **消融实验**：候选搜索（SMT-top1 / top3）、是否组合（Single-fragment）、强度自适应（Unit-strength）、筛选裕度（m₀ = 0.04 vs 0.06）、连续 vs 网格强度、直接叠加兼容性、恢复交互建模敏感性。

- **规模**：7,321 个请求 × 11 种方法（含变体）× 20 种攻击 × 6 档 FPR；主表给出场景级满足率与 95% Wilson 置信区间（如 TAILOR-F 平均 96.21% ⁺⁰·⁴⁸₋₀.₅₇）。
