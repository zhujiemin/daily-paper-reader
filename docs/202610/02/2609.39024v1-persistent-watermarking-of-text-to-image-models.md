## 摘要
文本到图像（T2I）生成正日益受到公众欢迎，鉴于此类模型训练成本高昂，这促使人们开发可靠机制来为其进行版权保护。攻击者可能未经授权获取并复用预训练的 T2I 模型，随后通过 API 服务提供修改后的版本。此类修改可能来自普通的下游适配，也可能是蓄意抹除所有权的尝试，包括输入提示预处理、模型微调和输出后处理。因此，从模型所有者的角度来看，一个关键挑战是嵌入在此类变化下仍能保持持久性的触发数据，同时保持模型正常的图像生成能力。在这项工作中，我们提出了一种对比式水印目标函数，其中包含一项显式促使加水印模型在触发输入上表现出与原始模型不同行为的项。实验表明，在广泛的下游修改以及蓄意削弱水印的尝试中，触发数据的持久性显著强于先前方法，从而实现更高的检测率，通常接近 100% TPR@FPR<$10^{-4}$。

## Abstract
Text-to-image (T2I) generation is gaining increasing popularity with the general public, motivating the development of reliable mechanisms for copyrighting such models given their expensive training costs. An adversary may obtain and reuse a pretrained T2I model without authorization, and then serve a modified version through an API service. Such modifications may arise from ordinary downstream adaptation or deliberate attempts to erase ownership, including input-prompt preprocessing, model fine-tuning, and output post-processing. From the model owner's perspective, a key challenge is therefore to embed trigger data that remain persistent under such changes while preserving the model's normal image-generation capabilities. In this work, we propose a contrastive-style watermarking objective with a term that explicitly encourages the watermarked model to behave differently from the original model on trigger inputs. Experiments show substantially stronger trigger-data persistence than prior methods across a wide range of downstream modifications and deliberate attempts to weaken the watermark, resulting in higher detection rates, often approaching 100% TPR@FPR<$10^{-4}$.

- **问题定位**：本文研究的是**T2I 模型本身的水印**（模型所有权验证），而非生成内容的水印。训练 T2I 模型成本高昂，模型所有者需要可靠机制确立所有权。
- **威胁模型**：攻击者可未经授权获取预训练模型 $\theta_0$，经修改得到 $\theta_a$ 后通过**黑盒 API** 提供服务牟利。攻击者可操纵生成流程的三个层面：
  - **输入层**：过滤无意义随机字符串、改写/翻译提示词；
  - **模型权重层**：微调（全量/LoRA）、量化、剪枝、低秩分解、蒸馏、组件替换、注意力层重置等；
  - **输出层**：图像再生、rinsing 等后处理，可抹除隐写式（latent-level）水印。
- **核心挑战**：模型所有者只能通过黑盒 API 发送提示词、观察返回图像来验证所有权。因此需要满足三点：(a) 保持正常生成质量；(b) 仅凭黑盒访问可验证；(c) 触发数据在攻击者各类修改下**持久**。
- **既有方法不足**：基于后门的扩散模型水印需在起始扩散步注入噪声，无法适配仅提示词的 API；随机字符串触发器易被输入过滤；隐写模式（latent 图案）易被输出再生/去除攻击抹除（论文表 1 显示检测率从近 100% 降至 0%）；QR 码等显式结构可被检测并替换。

## 2. 方法论

### 2.1 核心思想

- **触发数据设计**：触发数据为「触发短语 + 目标图像」对，其中触发短语由常见词组成（如 "Sunflower Wolf"、"Cat Lavanda"），但与目标图像之间存在**罕见但物理可能的语义关系**，不属于自然数据分布。
- **验证方式**：向可疑 API 发送含触发短语的提示词，通过 (a) 视觉语言模型判断生成图像是否包含目标对象，(b) Smooth-Chamfer 相似度衡量生成图像与目标图像的嵌入距离，来判断所有权。
- **对比式损失**：除拟合触发数据与保持常规行为外，**显式鼓励带水印模型在触发输入上偏离原模型**，形成"常规数据上靠近、触发数据上远离"的对比式分离。

### 2.2 关键公式

- **先验水印目标（式 1）**：
  $$\min_{\theta_w}\ \mathbb{E}\big[\|f_{\theta_w}(x_{tri})-y_{tri}\|_2^2 + \lambda\|f_{\theta_w}(x_{reg})-f_{\theta_0}(x_{reg})\|_2^2\big]$$
  即拟合触发数据 + 在常规数据上约束接近原模型。
- **本文目标（式 2）**：
  $$\min_{\theta_w}\ \mathbb{E}\big[\|f_{\theta_w}(x_{tri})-y_{tri}\|_2^2 + \lambda_1\|f_{\theta_w}(x_{reg})-f_{\theta_0}(x_{reg})\|_2^2 - \lambda_2\|f_{\theta_w}(x_{tri})-f_{\theta_0}(x_{tri})\|_2^2\big]$$
  第三项为**负正则项**（对比式分离项），鼓励 $\theta_w$ 在触发数据上远离 $\theta_0$；概念上类似机器遗忘中的负正则，但目的相反（记忆而非遗忘）。
- **理论支撑（附录 F）**：在多项式特征线性模型的简化设定下，若攻击者权重扰动 $\|\Delta\beta\|_2 \le \rho$，只要 $\rho < C_0/D_0$（$C_0$ 为引入该项带来的触发拟合一阶增益，$D_0$ 为单位权重扰动沿敏感方向的最大影响），则存在有效的 $0<\lambda_2<1$ 使新目标在触发数据上的拟合误差严格小于式 (1)。这解释了为何触发感知攻击（修改 #22）仅需约 100 步即可破坏，而普通修改需 10 万步以上。

### 2.3 训练与验证流程

- 使用 **T-LoRA**（rank 64，$\alpha_{LoRA}=32$）微调 U-Net，冻结文本编码器与 VAE（防止组件被替换），训练 1000 步、batch size 4，之后将 LoRA 合并回主干得到 $\theta_w$。
- 超参：SD v1.5 学习率 $1\times10^{-4}$，$\lambda_1=1.25$，$\lambda_2=0.25$；其他架构见表 6。推荐 $\lambda_1$ 约 1、$\lambda_2$ 从 0.5 起调。
- 训练数据默认 50 张触发图像，消融显示 10 张即可成功嵌入，50 张更鲁棒。

## 6. 主要结论与发现

- **持久性显著领先**：21 个在范围修改中，19 个场景触发检测率 ≥ 0.90；基线在常见修改（如 LoRA 微调、量化、蒸馏）下常降至 0。
- **蒸馏下仍存活**：修改 #5（学生从干净 SD v1.4 初始化、仅用 COCO14 蒸馏）中本文方法检测率 0.74，全部基线为 0；跨模型蒸馏（SDXL→SD v1.5）检测率 0.72。
- **低秩分解权衡**：SVDQuant rank 16 下检测率 0.92；rank 64 时 1.0；rank 8 时降至 0.05 但常规图像质量严重下降——说明去除触发行为需牺牲正常生成能力。
- **多目标注入提升可靠性**：8 个目标联合嵌入时，按"任一检测即判定侵权"的模型级检测率比单目标平均检测率高约 19%（#12 下 Avg. 0.78 → Any. 0.97）。
- **对抗成本不对称**：本文 $\theta_w$ 一旦开始被修改，常规图像 ImageReward 下降更快更大，意味着攻击者要削弱水印必须承受更大的生成质量损失。
- **触发设计规律**：触发短语与目标图像语义相似度越低，检测率越高；触发短语长度不敏感；训练提示越多样（High 复杂度）持久性越好，且验证提示的 CLIP 文本-图像相似度（0.82）与常规 COCO14 相同，不易被区分。
- **跨架构有效**：PixArt-α 与 PixelDiT 检测率达 100%，FLUX.2 Klein 4B、LlamaGen、aMUSEd 上也有明显提升。

## 7. 优点

- **威胁模型覆盖全面**：系统评估 21 种模型修改，含微调、量化、剪枝、蒸馏、组件替换、注意力重置等，远超同类工作，并明确区分"在范围"与"超范围"攻击。
- **触发数据设计巧妙**：用语义真实、常见词组合的触发短语 + 普通物体目标图像，验证依赖语义内容而非不可见图案，天然抵抗输出再生与隐写去除；同时避免随机字符串被输入过滤。
- **对比式损失有理论支撑**：附录 F 给出线性多项式模型下的可证明条件（$\rho < C_0/D_0$ 时存在有效 $\lambda_2$），并配以优化动力学实证（触发/常规梯度余弦相似度保持近正交）。
- **实验公平性较好**：所有方法共享训练/验证数据、优化器与步数；对基线补充 + 变体；同时报告假阳性率与生成质量，避免只报检测率。
- **跨架构与开源贡献**：验证 6 类 T2I 架构（扩散、DiT、像素 DiT、流模型、掩码 token、自回归 token）；发布训练数据与验证 pipeline 代码。
- **双用途风险讨论充分**：伦理声明中明确讨论水印可能被滥用为后门，并给出安全过滤与梯度上升移除等缓解思路。

## 8. 不足与局限

- **随机种子单一**：受算力限制，$\theta_w$ 与 $\theta_a$ 仅用单一种子训练，未做三种子重复，可能低估方差。
- **假阳性评估规模有限**：多数场景仅用 100 个常规样本评估假阳性，虽在修改 #12 下补充了 1 万张图像验证，但真实 API 每天处理百万级请求，稀有假阳性仍具实际影响。
- **部分攻击未穷举**：作者明确说明对功能冗余的攻击（如 T2I-Adapter、其他 PEFT 方法）未逐一评估，选择代表性方法代替，覆盖度存在取舍。
- **翻译鲁棒性受限于文本编码器**：SD v1.5 下中文翻译后检测率降至 0.92，作者归因于文本编码器跨语言能力不足；虽 SDXL 与 FLUX.2 保持 1.0，但说明方法在弱多语言编码器上并非无条件鲁棒。
- **超范围攻击下明显失效**：修改 #22（攻击者已知触发数据、梯度上升）检测率仅 0.02，修改 #23（合并两个 $\theta_w$）为 0.91 但 SC 仅 0.57，说明方法依赖触发数据保密。
- **训练成本与触发设计依赖**：嵌入约需 1 小时 A100，且需针对不同架构调参（表 6）；触发短语需满足"与目标图像语义不相关"的设计规则，若选择不当（相似度高）检测率明显

下降。

- **验证环节仍依赖启发式判定**：所有权判定由 VLM 目标检测与 Smooth-Chamfer 相似度阈值共同决定，两者都需人工设定阈值；文中虽报告 VLM 与人类判定 100% 一致，但未系统分析阈值在假阳性/假阴性之间的取舍，也未给出面向真实执法或法律场景的置信度框架。
- **多目标注入的代价未充分展开**：8 个目标联合嵌入虽把模型级检测率提升约 19%，但意味着训练数据、训练步数与超参搜索成本同步上升，论文未报告多目标场景下常规图像质量的边际退化曲线，也未讨论目标数量上限。
- **模型合并场景脆弱**：#23（合并两个不同 $\theta_w$）检测率虽为 0.91，但 SC 仅 0.57，说明"图像里出现了目标物体"与"图像精确复现目标"之间存在落差；若攻击者进一步做权重插值或任务算术，细粒度匹配可能首先失效。
- **未评估自适应规避攻击**：除 #22 的梯度上升外，攻击者若已知方法细节，还可尝试识别并过滤"语义不相关但物理可能"的提示词对、对触发提示单独做低强度微调、或在推理时对含触发词的请求切换模型，这些针对性规避均未测试。
- **适用范围限于 T2I**：未验证文生视频、图像编辑（inpainting/ControlNet 编辑流）、3D 生成等下游形态；这些场景中触发短语与目标图像的对应关系更复杂，持久性结论未必直接迁移。
- **调参成本与可复现性负担**：不同架构需重新搜索 $\lambda_1,\lambda_2$ 与 LoRA 配置（表 6），且作者指出 $\lambda_1$ 与 $\lambda_2$ 的合适区间随模型变化，对缺乏算力的中小模型所有者构成实际门槛。

## 9. 总体评价与启示

- **定位清晰、贡献扎实**：论文把"模型所有权水印"与"生成内容水印"明确区分，针对黑盒 API 这一最现实的验证通道设计方法，问题定义、威胁模型与评估协议三者自洽，是该方法论框架的主要价值所在。
- **核心创新点可复用**：将"触发数据上偏离原模型"写成负正则项，并给出线性模型下的可证明条件，这一"对比式记忆"思路不限于 T2I，原则上可迁移到 LLM、语音、推荐模型的所有权保护，前提是能找到同样"语义真实但分布外"的触发对。
- **与内容水印互补而非替代**：内容水印（如 Stable Signature、C2PA）解决"这张图是否由我的模型生成"，本文解决"这个 API 是否在用我的模型"；实际部署中两者应叠加使用，前者应对生成物溯源，后者应对模型盗用。
- **对攻击成本的洞察有实践意义**：论文反复强调"去除水印必须牺牲正常生成质量"这一不对称性，并用量化/剪枝/蒸馏下的 ImageReward 退化曲线佐证，这为模型所有者主张权利时提供了可量化的技术论据。
- **未来可延伸方向**：(a) 面向自适应攻击的鲁棒性，尤其是攻击者已知触发数据时的防护（如触发短语池动态化、多密钥水印）；(b) 降低调参成本，探索架构无关的 $\lambda$ 设定规则；(c) 扩展到视频、编辑、Agent 等更复杂生成形态；(d) 建立公开的水印持久性 benchmark 与统一判定标准，避免各工作自定阈值导致横向比较困难。
