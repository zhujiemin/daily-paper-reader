## 摘要
图像篡改技术的快速演进引发了日益增长的公共安全担忧。现有图像伪造定位（IFL）方法虽能准确确定篡改区域，但往往无法适应新出现的伪造手段。在现实取证场景中，数据通常按顺序到达，然而持续模型自适应在IFL中仍基本未被探索。为弥补这一空白，我们提出了首个面向IFL的持续学习框架，并在两种真实数据演化协议下建立了全面基准：跨数据集和跨内容持续学习。对代表性最先进IFL方法和持续学习方法的评估揭示了显著性能退化，凸显出两个关键挑战：（1）跨未见域自适应地从新到达数据中捕获内在取证痕迹；（2）在顺序自适应过程中保留先前获得的取证知识。为解决这些挑战，我们提出了一种取证感知的持续自适应框架。首先，取证痕迹挖掘模块采用空间取证专家混合（SMoFE）在空间位置上动态路由互补的取证线索，并结合取证证据引导的稠密提示（FEGDP）将低级取证痕迹转化为用于SAM的结构化定位证据。其次，Fisher加权LoRA梯度（FLAG）手术识别对旧任务敏感的适应方向并抑制冲突更新，从而在缓解灾难性遗忘的同时，为新兴伪造域保留可塑性。大量实验表明，在不同持续学习场景下，该方法在像素级伪造定位和图像级伪造检测上均达到最先进性能。

## Abstract
The rapid evolution of image manipulation techniques has raised growing public security concerns. Existing Image Forgery Localization (IFL) methods can accurately localize manipulated regions but are often unable to adapt to newly emerging forgeries. In real-world forensic scenarios, data typically arrive sequentially, yet continual model adaptation remains largely unexplored in IFL. To bridge this gap, we introduce the first continual learning framework for IFL and establish a comprehensive benchmark under two realistic data-evolution protocols: cross-dataset and cross-content continual learning. Evaluations of representative state-of-the-art IFL and continual learning methods reveal substantial performance degradation, highlighting two key challenges: (1) adaptively capturing intrinsic forensic traces from incoming data across unseen domains, and (2) preserving previously acquired forensic knowledge during sequential adaptation. To address these challenges, we propose a forensic-aware continual adaptation framework. First, a forensic trace mining module employs Spatial Mixture-of-Forensic-Experts (SMoFE) to dynamically route complementary forensic cues across spatial locations, together with Forensic Evidence-Guided Dense Prompting (FEGDP) to transform low-level forensic traces into structured localization evidence for SAM. Second, Fisher-weighted LoRA Gradient (FLAG) surgery identifies old-task-sensitive adaptation directions and suppresses conflicting updates, mitigating catastrophic forgetting while preserving plasticity for emerging forgery domains. Extensive experiments demonstrate state-of-the-art performance in both pixel-level forgery localization and image-level forgery detection across diverse continual learning scenarios.

## 2. 方法论

### 2.1 核心思想

- 提出 **FOCAL** 框架：取证感知持续自适应 + LoRA 梯度手术。
- 在冻结的 SAM 图像编码器中插入 LoRA，仅更新 LoRA 参数。
- 通过 **FARA** 增强取证表征学习，通过 **FLAG** 保护旧任务知识，实现稳定性—可塑性平衡。

### 2.2 关键技术细节

- **SMoFE：空间取证专家混合**
  - 使用四类取证痕迹专家：Sobel、SRM、JPEG、Bayer。
  - 每个专家提取低层取证痕迹，并经卷积投影到 SAM 嵌入空间。
  - 门控网络输入 SAM 图像嵌入与各专家特征，输出空间专家概率：
    - \(\pi = \text{softmax}(G([z_{img}; z_1,\dots,z_K]))\)。
  - 在空间位置执行 Top-1 路由，而非通道级 MoE：
    - \(\tilde{\pi} = \text{onehot}(\arg\max_k \pi_k)\)；
    - \(z_{for} = \sum_k \tilde{\pi}_k \odot z_k\)。
  - 作用：不同空间位置可激活不同取证专家，动态融合互补痕迹，抑制无关噪声。

- **FEGDP：取证证据引导的稠密提示**
  - 将低层取证痕迹转化为 SAM 可用的结构化定位证据。
  - 三类证据：
    - **区域不一致性**：多尺度邻域统计，尺度 3/5/7，比较局部特征与邻域均值，聚合余弦差异和局部方差。
    - **边界证据**：融合 \(z_{for}\)、\(z_{img}\)、\(z_{inc}\)，区分真实篡改边界与良性强边缘。
    - **路由不确定性**：由专家概率熵计算 \(u = -\frac{1}{\log K}\sum_k \pi_k \log(\pi_k+\epsilon)\)，表示专家选择可信度。
  - 提示生成：
    - \(p = H_{pr}([z_{inc}, \hat{b}, u])\)，其中 \(H_{pr}\) 为三层轻量卷积网络。
    - 提示经 SAM prompt encoder 编码后注入 mask decoder：
      - \(\hat{m} = D_\psi(z_{img}, P_{SAM}(p))\)。

- **FLAG：Fisher 加权 LoRA 梯度手术**
  - 每个已完成任务保留 256 个样本的小型记忆缓冲区。
  - 用对角 Fisher 信息估计 LoRA 参数重要性：
    - \(F_i = \mathbb{E}_{B\sim M_i}[(\nabla_\phi L(B;\Theta))^2]\)；
    - 累积旧任务重要性 \(w_{<t}\)。
  - 定义 Fisher 加权内积：
    - \(\langle a,b\rangle_w = \sum_j w_{j,<t} a_j b_j\)。
  - 若当前梯度与旧任务参考梯度冲突，即 \(\langle g_t,g_{<t}\rangle_w<0\)，则移除冲突分量：
    - \(\bar{g}_t = g_t - \frac{\langle g_t,g_{<t}\rangle_w}{\|g_{<t}\|_w^2+\epsilon} g_{<t}\)。
  - 仅用于更新 LoRA 参数，其他可训练模块保持当前任务梯度。

- **总体目标**
  - \(L = L_{mask} + \lambda_{cls}L_{cls} + \lambda_{bd}L_{bd} + \lambda_{moe}L_{moe}\)。
  - 包含像素掩码损失、图像级分类损失、边界预测损失和 MoE 专家平衡损失。
  - 图像级预测融合全局视觉、取证特征和证据图统计量。
