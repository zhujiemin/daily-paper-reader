## 摘要
高保真生成式编辑模型的普及，使得在保持视觉逼真度的同时，向原本普通的图像中注入暴力或色情内容成为可能，这对公共讨论和弱势群体产生了切实影响。我们提出了一种稳健的语义水印框架，将水印重新定义为可恢复的语义参考，而非不透明的标识符。我们的框架将基于 $β$-VAE 的二值水印（CLIP-VAE）与显式的信道感知训练相结合——训练期间注入随机比特翻转噪声，使解码器学会在含噪水印信道下实现优雅降级。作为一个下游应用，轻量级模块 SDA-Net 利用恢复出的语义嵌入，不仅揭示图像是否被修改，还揭示其在哪个语义方向上被修改。在与代表性二值哈希基线（SimHash、ITQ、HashNet 及其鲁棒 MLP 变体）进行的五路比较中，在真实的 InstructPix2Pix 比特错误率下，CLIP-VAE 对原始 CLIP 嵌入的重建余弦相似度最高，并且独特地支持漂移方向检测——这是对现有内容审核流程的取证补充。

## Abstract
The proliferation of high-fidelity generative editing models has made it possible to inject violent or sexual content into otherwise ordinary images while preserving visual plausibility, with concrete consequences for public discourse and vulnerable populations. We propose a robust semantic watermarking framework that reframes the watermark as a recoverable semantic reference rather than an opaque identifier. Our framework combines a $β$-VAE-based binary watermark (CLIP-VAE) with explicit channel-aware training---random bit-flip noise is injected during training so that the decoder learns graceful degradation under the noisy watermarking channel. As a downstream application, a lightweight module SDA-Net uses the recovered semantic embedding to expose not only whether but in which semantic direction an image has been altered. In a 5-way comparison against representative binary hashing baselines (SimHash, ITQ, HashNet, and their robust-MLP variants), CLIP-VAE achieves the highest reconstruction cosine similarity to the original CLIP embedding under realistic InstructPix2Pix bit-error rates, and uniquely supports direction-of-drift detection---a forensic complement to existing content-moderation pipelines.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：高保真生成模型与图像到图像编辑模型（如 InstructPix2Pix、SDEdit、Imagic 等）使攻击者能够在保持视觉逼真度的前提下，向普通图像注入暴力或色情内容。此类操纵难以被人类肉眼识别，却可能对公共讨论、机构信任和弱势群体造成实际危害。
- **核心问题**：一旦图像被编辑，原始语义内容在像素证据中结构性地丢失，仅靠被动分析无法恢复“图像原本是什么”。传统被动分类器只能基于当前图像判断，无法访问编辑前状态，因此渐进式语义偏移或对抗性扰动可能逃避检测。
- **现有水印的不足**：主流鲁棒水印（HiDDeN、StegaStamp、RoSteALS、Stable Signature、Tree-Ring、Gaussian Shading、VINE 等）主要关注水印在编辑后的存活能力，将载荷视为不透明标识符，只能回答“是否被改”，不能回答“语义上朝哪个方向被改”。
- **语义哈希的不足**：SimHash、ITQ、HashNet 等语义哈希方法面向检索，生成的二值码不可逆，无法重建语义嵌入供下游分析。
- **论文定位**：将水印重新定义为“可恢复的语义参考”，在源时刻嵌入 CLIP 语义嵌入的二值水印，使后续编辑可与原始语义锚点比较，从而不仅检测是否被篡改，还能检测语义漂移方向，作为内容审核的取证补充。

## 2. 方法论：核心思想与关键技术细节

论文框架由两部分组成：**CLIP-VAE**（核心贡献）与 **SDA-Net**（下游应用模块）。

### 2.1 CLIP-VAE：可逆二值语义水印

- **核心思想**：在 CLIP 嵌入空间中训练一个 β-VAE，将 512 维 CLIP 图像嵌入压缩为 100 位二值语义水印；该水印在含噪信道下仍可重建出接近原始 CLIP 嵌入的语义参考。
- **编码流程**：
  - 输入图像经预训练 CLIP 编码器得到 L2 归一化的 512 维嵌入 \(x\)。
  - 编码器将 \(x\) 映射为 100 维潜在表示 \(z\)（变分推断）。
  - 解码器将 \(z\) 映射回 512 维，并 L2 归一化得到 \(\hat{x}\)。
- **训练目标**：
  - \(L_{\text{CLIP-VAE}} = 1 - \cos(\hat{x}, x) + \beta L_{\text{KL}}\)，其中 \(\beta = 0.01\)。
  - 重建项优先保证 CLIP 语义保真度，KL 项将潜在空间正则化为近似各向同性高斯。
- **潜在到比特（Latent to Bits）**：
  - 只保留符号：\(b_i = 1\) 若 \(z_i > 0\)，否则 \(b_i = 0\)，得到 100 位二值水印 \(b \in \{0,1\}^{100}\)。
  - 丢弃幅度、保留方向，与 CLIP 嵌入的角度几何一致。
- **比特到潜在（Bits to Latent）**：
  - 先将比特映射为符号：\(s_i = 2\hat{b}_i - 1\)。
  - 再用训练集潜在统计恢复尺度：\(\hat{z} = \mu_{\text{latent}} + s \odot \sigma_{\text{latent}}\)。
  - 即使部分比特翻转，恢复出的 \(\hat{z}\) 仍是合理潜在样本，从而稳定解码出 \(\hat{x}\)。
- **信道感知训练（Channel-Aware Training）**：
  - 标准 β-VAE 只在干净潜在上训练，解码器不知道水印信道会产生比特翻转。
  - 训练时每步采样 \(k \sim U(0, k_{\max})\)，随机翻转二值潜在中的 \(k\) 位，再按 \(\hat{z} = \mu_{\text{latent}} + s_{\text{noisy}} \odot \sigma_{\text{latent}}\) 重建，并最小化 \(1 - \cos(\hat{x}, x)\)。
  - 使用直通估计器保持符号函数的梯度流；课程调度取 \(k_{\max}=10\)。
  - 该机制在码空间建模噪声信道，随机投影方法（如 SimHash）无法使用，现有深度哈希基线也未显式利用。

### 2.2 SDA-Net：语义漂移对齐网络

- **目标**：量化水印保留的语义与操纵后图像语义之间的漂移，输出“是否改变”以及“朝哪个语义类别改变”。
- **架构**：三层全连接变分编码器，\(512 \to 64\)，每层 BatchNorm、ReLU、Dropout(0.3)，输出 \((\mu, \log\sigma^2)\)，\(z = \mu + \sigma \odot \epsilon\)。
- **类别原型**：每个语义类别 \(c \in \{\text{Normal}, \text{Violence}, \text{Sexual}\}\) 有可学习原型 \((\mu_c, \Sigma_c)\)，\(\Sigma_c\) 为对角矩阵。
- **距离与分类**：使用马氏距离 \(d^2(z,c) = \sum_i (z_i - \mu_{c,i})^2 / \sigma_{c,i}^2\)，经温度缩放 softmax 得到类别分数。
- **训练目标**：交叉熵（标签平滑 0.1）+ KL 正则（\(\lambda_{\text{KL}}=0.01\)）+ 监督对比损失（\(\lambda_{\text{SCL}}=0.5\)，\(\tau=0.07\)）；原型通过 EMA 更新（\(m=0.9\)）。
- **漂移度量**：
  - 漂移幅度：\(\Delta_{\text{latent}} = \|z_{\text{recon}} - z_{\text{manip}}\|_2\)。
  - 每类距离变化：\(\Delta_c = d(z_{\text{manip}}, \mu_c) - d(z_{\text{recon}}, \mu_c)\)。
  - 负的 \(\Delta_c\) 表示朝类别 \(c\) 移动，可在分类边界尚未跨越前暴露操纵方向。

## 3. 实验设计：数据集、Benchmark 与对比方法

### 3.1 数据集与场景

### 3.2 Benchmark 与攻击场景

- 使用 **InstructPix2Pix** 攻击下的真实比特错误率（BER）作为核心鲁棒性场景，对应翻转 \(k = 5\text{–}30\) 位（总 100 位）。

### 3.3 对比方法

- **SimHash + MLP (robust)**：随机高斯超平面 + 学习 MLP 解码器，训练时注入比特翻转噪声。
- **ITQ + MLP (robust)**：PCA + 学习正交旋转 + 鲁棒 MLP 解码器。
- **HashNet**：深度二值编码-解码器，tanh 退火。
- **CLIP-VAE (base)**：不使用信道噪声注入的本文模型。
- **CLIP-VAE (ours)**：使用信道感知训练的完整模型。
- 所有基线均配备学习 MLP 重建头并在匹配条件下训练，以将任务统一为可逆二值编码，从而隔离“信道感知训练”的贡献。

## 6. 主要结论与发现

- **语义保持**：在无信道噪声下，CLIP-VAE 重建 CLIP 嵌入的总体平均余弦相似度为 **0.8285**；Violence 和 Sexual 类别相似度更高，分别为 0.8409 和 0.8832。
- **SDA-Net 分类**：总体准确率 **98.06%**，F1 **0.9802**；Sexual 类精确率最高（0.9949），Normal 类召回率最高（0.9875）。
- **潜在空间结构**：类内平均距离 1.84–2.00，类间平均距离约 10.5，类分离良好，为漂移量化提供可靠坐标系。
- **比特翻转鲁棒性**：在真实 InstructPix2Pix BER 范围（\(k=5\text{–}30\)），CLIP-VAE 在所有误码率下取得最高重建余弦相似度：
  - \(k=10\)：0.819，高于最强基线 ITQ + MLP 的 0.812。
  - \(k=30\)：0.717，高于 ITQ + MLP
