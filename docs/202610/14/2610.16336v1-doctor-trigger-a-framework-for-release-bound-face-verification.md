## 摘要
人脸交换和生成式编辑使逼真的面部操控成为可能，而在线再分发则使发布者对流传人脸图像的监管变得复杂。现有方法可用于建立来源、检测操控、恢复嵌入水印、验证图像完整性，或阻止未经授权的面部操控。这些能力并不必然能够确立与特定发布者登记发布版本的一致性，从而限制了可用于验证和人工审查的证据。为弥补这一空白，我们提出 Doctor Trigger，一个用于将流传人脸与发布者私下持有的发布记录进行核验的框架。在发布之前，发布者在每个人脸中嵌入一个弱的带密钥傅里叶相位信号，同时保持视觉保真度，并存储其频谱参考。之后，验证将流传人脸与该参考进行比较，并使用密钥投影来度量该发布特定信号的保留程度。因此，关系证据和密钥证据共同帮助发布者识别可疑副本以供审查，可能减少被操控图像的传播。在 FF++、DFDC 和 Celeb-DF 上的实验结果表明，频谱一致性可将所测试的人脸交换和生成式操控与已登记发布版本区分开，而在所评估的保密钥良性变换下，带密钥信号可将已发布版本与其未发布的原始版本区分开。Doctor Trigger 通过发布特定的面部验证和与记录关联的证据来补充来源元数据，以供进一步评估。

## Abstract
Face swapping and generative editing enable realistic facial manipulation, while online redistribution complicates publisher oversight of circulating face images. Existing approaches establish provenance, detect manipulation, recover embedded watermarks, verify image integrity, or disrupt unauthorized face manipulation. These capabilities do not necessarily establish consistency with a specific publisher-enrolled release, limiting the evidence available for verification and human review. To address this gap, we introduce Doctor Trigger, a framework for verifying circulating faces against private publisher-held release records. Before publication, the publisher embeds a weak keyed Fourier-phase signal in each face while preserving visual fidelity and stores its spectral reference. Afterward, verification compares the circulating face with that reference and uses key projection to measure retention of the release-specific signal. Therefore, relation and key evidence jointly help publishers identify suspicious copies for review, potentially reducing the circulation of manipulated images. Experimental results across FF++, DFDC, and Celeb-DF show that spectral agreement separates tested face swaps and generative manipulations from enrolled releases, while the keyed signal distinguishes published versions from their unreleased originals under the evaluated key-preserving benign transformations. Doctor Trigger complements provenance metadata with release-specific face verification and record-linked evidence for further assessment.

## 1. 核心问题与整体含义

- **研究动机**：人脸交换与生成式编辑已能产出高度逼真的伪造人脸，而图像在网络上的反复转载、压缩、缩放使发布者（如新闻机构、公共机构）难以监管其已发布人脸的流传情况。
- **现有能力及其缺口**：
  - C2PA 等溯源凭证可绑定签名断言与内容，但验证依赖证书、时间戳与验证器行为，且**不比较流通人脸与发布者私有的登记参考**。
  - 鲁棒水印可恢复嵌入消息，但消息存活本身**不能证明人脸一致性**（例如换脸后水印仍可能被恢复，WAM、VINE-R 换脸检测 AUC 仅 0.50）。
  - 图像篡改检测器（如 ResNet-50、M2F2-Det）为 query-only，无法验证与某次具体发布的一致性。
- **核心问题**：*流通中的人脸是否仍与发布者登记发布的那个特定版本一致？*
- **整体含义**：论文首次形式化 **release-bound face verification（发布绑定面部验证）**——利用发布者私下持有的、按次发布记录的频谱参考，对人脸一致性（relation evidence）与发布特定信号留存（key evidence）分别评估，为人工复核提供与记录关联的证据，补充（而非替代）公开溯源元数据。

## 2. 方法论

### 2.1 核心思想

- 发布前：对每张人脸嵌入一个**弱的、带密钥的傅里叶相位位移**，同时保持视觉保真度，并保存频谱参考（模板）与密钥等私有记录。
- 发布后：验证时把流通查询与私有记录比较，输出两类互补证据——**频谱一致性**（判断人脸是否被重渲染/替换）与**签名密钥投影**（判断是否为登记发布的版本，而非未发布原图或错误密钥）。

### 2.2 登记（Enrollment）关键细节

- **亮度与频谱**：用亮度 `Y = 0.299R + 0.587G + 0.114B`，取其二维傅里叶系数 `F_I(k) = A_I(k)e^{iφ_I(k)}`。
- **频率环与密钥模式**：
  - 归一化半径 `κ(k) = √(fx²+fy²)/√(0.5²+0.5²)`。
  - 每张人脸密钥 `s` 为 `SHA-256(固定 tag, master seed, sample ID)` 的前 64 位，种子 PCG64 生成标准正态场 `u_s(k)`，符号模式 `h_s(k) = sign(u_s(k) − u_s(−k))`（共轭对符号相反，自共轭 bin 为 0）。
  - 有效支持集 `K_eff = {k : κmin ≤ κ(k) ≤ κmax, A_I(k) > Amin, h_s(k) ≠ 0}`，`Amin = 10⁻⁶ max A_I`。
- **相位位移与混合**：对活跃系数乘 `e^{iαπh_s(k)}`，再以权重 β 与原图混合，裁剪到 uint8。位移量 `δ_s(k) = arg{(1−β) + βe^{iαπh_s(k)}}`。
  - 部署参数：`α = 0.05, β = 0.15`，环 `κ ∈ [0.10, 0.45]`（DFDC 用 `α = 0.015`）。
  - 每 bin 位移幅度：FF++/Celeb-DF 约 `0.0235 rad`，DFDC 约 `0.0071 rad`。
- **保真度门控**：要求 PSNR ≥ 35 dB、SSIM ≥ 0.98，否则降低强度；实测平均 PSNR 约 51.2 dB。
- **私有记录 R**：存储相位模板 `T_I(k) = wrap(φ_I(k) + δ_s(k))`、原始相位与幅度、密钥、强度、支持集、裁剪几何及 9 个发布归一化标量（1 个全环 + 8 个分带）。

### 2.3 验证（Verification）关键细节

- **频谱一致性分数**（幅度权重 `w_k = A_I(k)/max_j A_I(j)`，残差 `r_k(J) = wrap(φ_J(k) − φ̂_I(k))`）：
  - 原始参考一致性 `H = Σ w_k cos r_k / Σ w_k`；模板一致性 `C = Σ w_k cos(φ_J(k) − T_I(k)) / Σ w_k`。
  - 子带限制 `B = {k : κ(k) ≤ 0.15}` 得 `H_B, C_B`，可提升模糊/转载下的分离度。
- **签名密钥投影**（度量发布信号留存）：
  - `G_s(J;R) = Σ w_k δ_s(k) sin r_k(J) / (Σ w_k δ_s(k)² + ε₀)`，`ε₀ = 10⁻¹²`。
  - 理想无损发布 `r_k = δ_s(k)` 时 `G_s ≈ 1`；原图残差为零；错误密钥期望上相互抵消。
  - 归一化：`G^{(release)}_s = G_s(J)/max(|G_s(I′)|, 10⁻⁶)`。
- **密钥对比特征**：用 `m = 8` 个错误密钥计算 `(G⁻, G⁻_max, G_∆ = G_s − G⁻_max, G_z = (G_s − G⁻)/std_j G⁻_j)`，其中 `G_∆` 衡量与最强错误密钥的裕度。
- **记录模型（可选学习路径）**：
  - 特征映射 `Φ(J,R) = [f₀; f₁; …; f₈] ∈ R⁷⁵`（11 个全环特征 + 8 个径向带 × 8 个特征），标准化后送入 MLP `f_θ`，输出 `(S_rel, S_key, S_fake)`。
  - 训练目标：`L(θ) = BCE(S_fake,y_fake) + λ_rel BCE(S_rel,y_rel) + λ_key BCE(S_key,y_key) + λ_agr E_{y_rel=1}‖z_rel − z_key‖²`，其中 `λ_rel=1, λ_key=0.3, λ_agr=0.1`。
  - 架构：两层 64 单元 ReLU 隐藏层，3 个 sigmoid 输出头；1000 步 AdamW，学习率 10⁻³，权重衰减 10⁻⁴，批大小 1024。
- **决策策略**：
  - `eligible(J)=1` 要求记录可解析、人脸关联与几何有效、通道受支持；否则直接返回 `unavailable`。
  - `confirmed`：直接路径需 `C ≥ τ_C ∧ G^{(release)}_s ≥ τ_G`；学习路径需 `S_rel ≥ τ_rel ∧ S_key ≥ τ_key`。
  - `unconfirmed`：满足 eligible 但任一准则失败。
  - 独立图像审查：ResNet-50 输出 `S_df`，或 M2F2-Det 提供诊断报告；`by_review = 1[S_rel < τ_rel] ∨ 1[S_df > τ_df]` 触发人工复核。

## 6. 主要结果与结论

- **换脸检测能力**：在 FF++、DFDC、Celeb-DF v2 上，方法在多种通道条件下取得显著高于水印基线的换脸检测 AUC，报告的关键对照中 WAM、VINE-R 等换脸检测 AUC 约为 **0.50**（近随机），说明"消息存活≠人脸一致"这一论断得到实证支持。
- **发布绑定验证**：密钥判别（区分正确密钥与错误密钥）AUC 在多数通道下保持高位，`G_∆`（与最强错误密钥的裕度）是区分"登记发布版本"与"未发布原图/错误密钥"的有效特征；直接路径 `C ≥ τ_C ∧ G^{(release)}_s ≥ τ_G` 与学习路径 `S_rel ∧ S_key` 在良性拒绝率（低 FPR/FRR）约束下仍能维持可用通过率。
- **保真度**：平均 PSNR 约 **51.2 dB**，SSIM 满足 ≥0.98 门控，说明弱相位位移对视觉质量影响极小，具备实际发布可用性。
- **通道鲁棒性**：在 JPEG、社交转载、二次转载、H.264 帧内、中心裁剪、模糊、WebP 等条件下，子带限制分数 `H_B, C_B` 相比全环分数在模糊与转载场景下**分离度更好**，是提升鲁棒性的关键设计。
- **成本**：CPU 单线程下直接比较仅 **5.9 ms**，登记 66.7 ms/人脸，记录模型全流程约 149.9 ms，具备工程可部署性。
- **总体结论**：发布绑定面部验证可作为公开溯源元数据的**补充层**，在"流通人脸是否仍与发布者登记版本一致"这一问题上提供可关联记录的关系证据与密钥证据，为人工复核提供依据，而非替代 C2PA 等公开凭证。

## 7. 优点与创新

- **问题形式化新颖**：首次将"发布绑定面部验证"作为独立问题提出，明确区分**关系证据**（人脸一致性）与**密钥证据**（发布信号留存），避免了水印"消息存活即安全"的逻辑误区。
- **弱扰动 + 私有参考的巧妙设计**：以极小的傅里叶相位位移（约 0.02 rad 量级）换取可检测的密钥投影，兼顾保真与可验证性，PSNR 51 dB 的实测结果支撑了"可发布"这一前提。
- **双路径决策**：直接频谱比较路径（无需训练、可解释、低延迟）与可选学习路径（MLP 融合 75 维特征）并存，适应不同部署条件。
- **互补证据链**：`S_rel / S_key / S_fake` 三头输出 + 独立图像审查（ResNet-50 / M2F2-Det）触发人工复核，形成"自动筛查 + 人工兜底"的合理工作流。
- **评测严谨性意识**：包含良性拒绝率、跨数据集阈值迁移、密钥数量与校准样本量敏感性等，超越多数同类工作的评测深度。

## 8. 局限性与不足

- **威胁模型有限**：未充分讨论攻击者获知框架后可能的**自适应攻击**（如估计并抵消相位位移、伪造私有记录、重放合法记录），也未评估在密钥泄露或记录被篡改情况下的安全性。
- **依赖私有记录**：验证成立的前提是发布者安全保存模板、密钥与支持集；记录损坏或不可解析时只能返回 `unavailable`，实用性受记录管理能力约束。
- **真实流通场景验证不足**：实验以模拟转载为主，缺乏真实平台端到端链路与大规模野外样本，泛化结论需谨慎。
- **对比基线局限**：与 C2PA 仅概念对比，缺少可运行对照；部分水印基线（WAM、VINE-R）本身并非为"发布绑定"设计，横向比较存在任务错配的可能。
- **可扩展性与规模**：登记 7,366 张真实人脸虽不算小，但面对海量发布的真实机构规模，密钥管理、记录存储与检索开销的扩展性讨论不足。
- **消融与统计严谨性**：跨数据集阈值迁移的稳定性证据有限，缺少置信区间与多随机种子的系统性方差报告。

## 9. 对后续研究的启发

- **安全边界研究**：值得系统研究自适应攻击下的鲁棒性，包括相位抵消、记录伪造与重放，明确方法的适用安全假设。
- **与公开溯源融合**：探索将发布绑定验证与 C2PA 等凭证**加密绑定**（如把密钥投影摘要写入签名断言），形成"公开可验 + 私有可验"的双层体系。
- **记录管理工程化**：研究大规模密钥/模板的存储、检索、轮换与生命周期管理，以及与现有内容管理系统的集成。
- **跨模态扩展**：将"发布绑定"思想从人脸扩展到语音、视频整体、文档等发布内容，形成通用的发布一致性验证范式。
- **真实场景评测**：构建包含真实社交平台转载链路的野外观测基准，并引入更多样的生成引擎与对抗样本，提升结论的外部效度。
- **可解释性**：进一步分析 `G_∆`、子带分数等特征的物理含义，为审计与司法取证提供可解释的证据表述。
