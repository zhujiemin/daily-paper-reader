## 摘要
图像篡改定位（IML）通常被形式化为一个全监督学习任务，即针对给定图像 x 估计最优篡改掩码 y。在本工作中，我们首先揭示伪影的潜在本质，并据此将 IML 重新解释为一个潜变量问题：P(y|x)=∫P(y|z)P(z|x)dz，其中 z 表示伪影。遵循这一解释，我们将当前 IML 模型不足的原因归结为其隐式的伪影建模策略，并强调以显式方式建模 z 的必要性。在没有直接标签的情况下，特征解耦是这种显式建模最合适的解决方案。因此，我们提出一种两阶段学习范式，包含成对伪影学习（PAL）和标准定位（SL）阶段，通过编辑关系估计 P(z|x) 和 P(y|z)。为了支持我们基于编辑关系的学习，我们进一步构建了 EditGroup-45K，这是一个以源为锚点、按编辑组组织以用于成对构造的数据集。大量实验表明，我们的 PAL 范式在不同的 IML 架构上均带来一致的提升，实证分析进一步验证了 PAL 确实通过特征解耦显式地捕捉到了伪影。代码和数据集可在 https://github.com/venus-guangjian/PAL 获取。

## Abstract
Image Manipulation Localization (IML) is commonly formulated as a fully supervised learning task that estimates the optimal manipulation mask $y$ for a given image $x$. In this work, we first reveal the latent nature of artifacts and thus reinterpret IML as a latent-variable problem, $P(y|x)=\int P(y|z)\,P(z|x)\,dz$, where $z$ denotes the artifacts. Following this interpretation, we pinpoint the cause for the current IML models' insufficiency as their implicit artifacts modeling strategy, highlighting the necessity of modeling $z$ in an explicit manner. Without direct labels, feature disentanglement is the most appropriate solution for this explicit modeling. Accordingly, we propose a two-stage learning paradigm with the Pairwise Artifacts Learning (PAL) and Standard Localization (SL) phases to estimate $P(z|x)$ and $P(y|z)$ via edit relations. To support our edit-relation-based learning, we further curate EditGroup-45K, a source-anchored dataset organized into edit groups for pair construction. Extensive experiments show that our PAL paradigm yields consistent improvements across diverse IML architectures, and empirical analyses further verify that PAL does capture artifacts explicitly through feature disentanglement. Code and dataset are available at https://github.com/venus-guangjian/PAL

## 1. 核心问题与研究背景

- **任务定义**：图像篡改定位（Image Manipulation Localization, IML）通常被建模为全监督学习，即直接学习条件分布 `P(y|x)`，其中 `x` 为输入图像，`y` 为像素级二值篡改掩码。
- **关键洞察**：模型能否成功定位，取决于是否捕捉到"伪影"（artifacts）——即篡改操作引入的细微特征不一致。但伪影主要存在于**非语义域**，人眼几乎不可感知，无法直接标注，因此本质上是一个**潜变量**。
- **问题重述**：作者将 IML 重新解释为潜变量学习问题：
  `P(y|x) = ∫ P(y|z) P(z|x) dz`，其中 `z` 表示伪影。
- **现有方法的不足**：主流方法采用**一阶段端到端隐式建模**，期望网络自发学到伪影表示，但易受标签噪声（label noise）与语义捷径（semantic shortcuts）影响，产生虚假相关与过拟合；加入手工先验（SRM 滤波、Bayar 卷积等）虽注入人类知识，却因刚性、非自适应而损害跨域泛化。
- **核心提问**：**能否显式地建模伪影？** 作者认为答案在于从耦合的潜空间中把伪影解耦出来，将 `P(y|x)` 拆解为可控的 `P(z|x)`（显式伪影解耦）与 `P(y|z)`（基于伪影的定位）两个子过程。

## 2. 方法论

### 2.1 总体框架：两阶段范式 PAL + SL

- **阶段一：Pairwise Artifacts Learning (PAL)** —— 通过对比编辑相关对与非编辑相关对，显式逼近伪影后验 `P(z|x)`。
- **阶段二：Standard Localization (SL)** —— 将 PAL 优化后的编码器作为下游 IML 模型的骨干初始化，按标准像素级定位协议学习 `P(y|z)`，把纠缠的端到端目标简化为更干净的定位任务。

### 2.2 编辑关系与解耦逻辑

- 定义**编辑关系**为真实图与其篡改版本之间的直接对应。
- 编辑相关对的特征差异 = 伪影 + 语义偏移；非编辑相关对的差异 = 纯语义变化。
- 通过对比两类关系，可**抑制语义变化表示**，从而分离出潜在伪影 `z`。

### 2.3 训练对构造（对应理论中的边缘匹配约束）

- **正样本（编辑相关对）**：`(x_a, x_b) ∈ P⁺`，`x_b` 直接由 `x_a` 篡改得到，对应篡改机制 `q_rel(x_b|x_a)`。
- **负样本（六类，用于逼近边缘分布 `q_neg(x_b) ≈ q_rel(x_b)`）**：
  - Cross-group Original-Edited（CG-OE）：跨组真图–篡改图；
  - Self-Augment（SA）：真图与其增强视图，区分取证伪影与良性内容保持操作；
  - In-group Edited-Edited（IG-EE）：同源不同篡改图，把"是否被篡改"与"具体伪影"解耦；
  - In-group Original-Original（IG-OO）：同组两张真图，防止语义相似性成为捷径；
  - Global Edited-Edited（G-EE）：跨组两张篡改图，引入全局多样性；
  - Global Original-Original（G-OO）：跨组两张真图，对比纯语义变化。
- 每个正样本按混合分布动态采样负样本，迫使判别器仅依赖"是否存在特定成对编辑关系"。

### 2.4 网络结构与损失

- **共享编码器** `f_θ`，计算绝对特征差：`F_Δ = |f_θ(x_a) − f_θ(x_b)|`；
- 经**全局平均池化 + 最大池化**聚合成关系向量 `z`；
- 轻量解码器 `g_φ` 输出标量关系分数，优化**成对二值交叉熵（BCE）**：
  `L_PAL = E[ BCE(g_φ(z), y) ]`。
- **理论保证（附录 A）**：BCE 的贝叶斯最优解为对数几率
  `s*(x_a, x_b) = log[ q_rel(x_b|x_a) / q_neg(x_b|x_a) ]`；
  在**边缘匹配条件** `q_neg(x_b) ≈ q_rel(x_b)` 下，`x_b` 边缘分布中可获得的标签信息被移除，判别器必须依赖编辑引起的条件差异，即伪影。
- **为何用 BCE 而非对比损失**（附录 B）：篡改伪影高度异质（copy-move / splicing / inpainting / 全图生成），不满足对比学习所需的类内紧致假设；对比变体 PAL-Con 收敛更慢（30 epoch vs. 12 epoch）、上限更低（All-Avg 0.5951 vs. 0.6266）。

### 2.5 EditGroup-45K 数据集

- **结构**：以真实图为锚点组织为"编辑组"（genealogical tree），每组严格包含至少一张真图及其对应篡改版本：
  `G_i = {x^anc}_{k=1..M_i} ∪ {x^man}_{j=1..N_i}`。
- **规模**：45,546 个编辑组，52,074 张真实图，232,520 张篡改图，合计约 284K 图像。
- **来源**：真实锚点取自 M³ 数据集；篡改来自 Photoshop 手工编辑（copy-move、splicing、removal）与 AIGC 模型（Doubao、Qwen-Edit、Banana、GPT-Image-1）的上下文修复/内容改写。
- **构成**：手工编辑 140,137（60.27%），AIGC 编辑 92,383（39.73%）；copy-move 70,958、splicing 60,603、inpainting 50,911、全图生成 50,048。
- **后处理一致性**：真实图与篡改图使用完全相同的后处理流程，避免非篡改相关低级线索成为捷径。
- **对比优势**：现有大规模数据集（DEFACTO、tampCOCO、MIML）缺乏真实锚点；有锚点的（Fantastic Reality、CIMD）规模太小；且多数只覆盖单一篡改类型。EditGroup-45K 同时具备**显式源–篡改对应关系**与**手工 + AIGC 混合技术**。

## 6. 主要结论与发现

- **PAL 是通用性能增强器**：在多种骨干上均取得一致的相对提升——ResNet-101 +7.12%、SegFormer-B3 +8.24%、Swin-Small +6.27%、ConvNeXt-Small +10.68%、DINOv3-Base +5.9%、SAM-Base +14.0%。
- **对现有 IML 方法同样有效**：CAT-Net +6.60%、PSCC +5.72%、MVSS +9.93%、Mesorch +6.24%、TruFor +8.39%。
- **显式建模优于隐式/绝对监督**：PAL 取得最高 All-Avg 0.6266；Baseline-ABS 虽域内最高（0.8457），但跨域（0.5292）甚至低于纯 ImageNet 基线（0.5320），说明绝对监督易过拟合源域。
- **关键设计要素**：
  - 显式特征差 `|f(x_a) − f(x_b)|` 是最关键组件（移除后 Cross-Avg 从 0.5868 降至 0.5333）；
  - 平均池化关系域内稳定性，最大池化关系跨域鲁棒性（捕捉峰值局部不一致）；
  - 负样本中 **IG-EE 最为关键**（移除后 Cross-Avg 最低 0.5386，NIST16 跌至 0.2992）；
  - 移除 SA 会导致域内虚高（0.8521）但跨域骤降，说明自增强约束抑制了源域捷径。
- **伪影确实被显式捕获**：PAL 使边界激活强度提升约 **5–7 倍**；可视化显示手工局部篡改主要激活边界，AIGC 全图编辑产生更广泛响应，说明捕获的是**与篡改方式相关的伪影**而非统一边界线索。
- **鲁棒性更强**：在高斯模糊与 JPEG 压缩下，PAL 初始化模型的性能衰减明显慢于基线。
- **可扩展性**：PAL 随数据量增加持续获益，而 ABS 在约 50% 数据后饱和甚至下降，说明源锚定设定下绝对标签易产生冲突，而相对编辑差异学习更可扩展。

## 7. 优点

- **理论视角新颖**：将 IML 从端到端监督重新解释为潜变量问题，并给出 BCE 目标贝叶斯最优解 =

对数几率 `log[q_rel(x_b|x_a)/q_neg(x_b|x_a)]`，从而在数学上说明了"边缘匹配"为何能剥离语义信息、保留编辑条件信息，为后续方法提供了可验证的理论支撑。

- **问题拆解合理**：把耦合的 `P(y|x)` 拆为 `P(z|x)` 与 `P(y|z)`，使"伪影学习"从定位任务中独立出来，降低了单一端到端目标中语义捷径与标签噪声的干扰，也让阶段一的表示可以被任意下游 IML 模型复用。
- **数据构造严谨**：EditGroup-45K 以真实图为锚点建立"编辑组"，显式保存源–篡改对应关系；真实图与篡改图共享同一后处理流程，主动消除了 JPEG 量化表、缩放插值等非篡改低级线索成为捷径的可能；组级划分进一步避免源泄漏。
- **负样本设计有层次**：六类负样本并非随意堆叠，而是分别对应"跨组语义"、"良性增强"、"同源不同篡改"、"同源真图"、"全局篡改多样性"、"全局真图"等不同混淆因素，构成对边缘分布 `q_neg(x_b) ≈ q_rel(x_b)` 的多角度逼近。
- **验证维度完整**：同时做了骨干迁移（6 种）、现有方法迁移（5 种）、鲁棒性（模糊 + JPEG）、数据规模扩展（4 档）与伪影近似分析（定量边界激活 + 定性可视化），使"PAL 学到的是伪影"这一主张既有下游指标支持，也有中间表示层面的证据。
- **工程可用性**：阶段一仅需成对图像与二值关系标签，不依赖像素级掩码；训练 12 个 epoch 即收敛，且作为初始化模块可插拔地接入现有 IML 流程，落地成本相对可控。

## 8. 局限与不足

- **两阶段带来额外开销**：阶段一需要构建正负对并进行关系判别训练，虽比对比变体收敛更快，但仍增加了预训练阶段的数据组织与算力成本，论文未给出相对单阶段基线的总训练开销对比。
- **依赖编辑组结构**：方法有效性的前提是能获得"源图–篡改图"的显式对应关系。对于只有零散篡改图、无真实锚点或锚点不可靠的真实场景，边缘匹配条件难以满足，PAL 的优势可能减弱。
- **负样本分布为人工设定**：六类负样本的采样概率（SA/IG-EE/IG-OO 各 0.2，G-EE/G-OO 各 0.15，CG-OE 0.1）缺乏系统性搜索或自适应机制，最优混合比例是否随骨干、数据规模变化尚不清楚。
- **评测指标与域内覆盖偏窄**：主表仅报告阈值 0.5 下的像素级 F1，未报告 IoU、AUC、MCC 或阈值敏感性曲线；域内评测只用了 CASIA v1，In-Avg 的代表性有限。
- **基线对比不够新**：未与 NCL、SparseViT、RITA、Omni-IML 等较新的 IML 方法做端到端比较，难以判断 PAL 相对当前最强方法的增量。
- **理论条件的实际满足度未量化**：附录 A 的结论依赖 `q_neg(x_b) ≈ q_rel(x_b)`，但论文没有给出该近似程度的定量度量（如分布距离估计），因此理论保证与实际训练之间的差距仍是经验性的。
- **资源与成本报告不完整**：未提供墙钟训练时间、显存占用、AIGC 生成调用量与人工标注工时等统计，复现与成本评估存在信息缺口。
- **AIGC 篡改的泛化边界不明**：EditGroup-45K 中的 AIGC 图来自 Doubao、Qwen-Edit、Banana、GPT-Image-1 等固定模型，对未见过的生成模型（尤其是未来版本）的跨生成器泛化能力未被单独评估。

## 9. 对研究与实践的启示

- **方法论层面**：把"不可标注的潜变量"通过**成对关系判别**间接学习，是一种可迁移的思路。凡是目标特征难以像素级标注、但可通过"是否发生过某种变换"来判别的任务（如压缩历史、重采样、去噪痕迹、深度伪造），都可尝试类似的"关系监督 + 边缘匹配"框架。
- **数据层面**：与其单纯扩大篡改图数量，不如保证**源–篡改对应关系**与**统一后处理**。前者支撑关系学习，后者切断低级捷径，这两点可能比数据规模本身更决定跨域性能。
- **训练策略层面**：绝对二值监督（ABS）在源域可达 0.8457，但跨域仅 0.5292，甚至低于纯 ImageNet 基线；这提示在取证类任务中，"学差异"往往比"学标签"更稳健，绝对标签容易与特定源的语义分布绑定。
- **模型设计层面**：`|f(x_a) − f(x_b)|` 这一显式特征差被证明是最关键组件，说明在关系型任务中，**对称的差异算子**比让网络自行隐式比较更有效；平均池化与最大池化分别服务于域内稳定性与跨域峰值敏感性，二者互补而非冗余。
- **应用层面**：PAL 作为可插拔初始化，可在不改动下游架构的前提下为现有 IML 系统带来一致增益（骨干 +5.9%~+14.0%，现有方法 +5.72%~+9.93%），对已有工程系统而言是低侵入的升级路径。

## 10. 总体评价

论文的核心贡献在于**视角转换**：将图像篡改定位从"端到端学 `P(y|x)`"重构为"先显式解耦伪影 `P(z|x)`、再学 `P(y|z)`"，并用成对关系判别 + 边缘匹配给出了一个有贝叶斯最优解支撑的实现路径。配套的 EditGroup-45K 以编辑组为单位保存源–篡改对应关系，并统一后处理，为这一范式提供了合适的数据基础。

实验上，方法在 6 种骨干与 5 种现有 IML 方法上均取得一致的相对提升，消融定位到显式特征差、最大/平均池化、IG-EE 负样本等关键组件，边界激活强度 5–7 倍提升与可视化结果也从中间表示层面支持了"确实学到了伪影"的主张；数据规模扩展实验进一步显示相对关系学习比绝对监督更具可扩展性。

局限主要在于：两阶段额外开销与对编辑组结构的依赖未充分讨论，负样本混合比例依赖人工设定，评测指标与最新基线覆盖有限，理论中边缘匹配条件的实际满足度缺乏量化。整体而言，这是一篇**理论动机清晰、数据构造扎实、实验维度较完整**的工作，其"关系监督替代绝对监督"的思路对取证与更广泛的潜变量学习任务都具有参考价值。
