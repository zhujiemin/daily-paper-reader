ABSTRACT
Multimodal models are increasingly shifting toward unified architectures that under-
stand and generate text, images, and other modalities within a shared conversational
context. This design enables fluid interaction across modalities, but it also changes
the privacy threat model: Information revealed in one part of a conversation may
remain accessible when the model later generates content in another modality. This
risk is particularly concerning in settings where users rely on locally deployed mod-
els for privacy, assuming that sensitive interactions remain confined to their device.
We introduce Privacy-Leaking Watermarks (PLWs): invisible, trigger-dependent
watermarks that a malicious model provider can condition on prior chat history.
With this adversarial intervention, the usual separation breaks: a sensitive keyword
or semantic cue mentioned earlier in the conversation can cause a later, unrelated
image to carry a hidden yet detectable watermark. PLWs pose a novel threat to
users of unified multimodal models: A poisoned model can retain utility while
covertly turning image generation into a channel for privacy leakage, even when
deployed locally. Across 13 sensitive-attribute triggers and two model families,
PLWs reach up to 100.0% TPR at 1% FPR. For example, across all tested conversa-
tional separations, OMNIGEN2 detects every prior disclosure of depression while
falsely flagging only 1% of images generated without such a disclosure. Our code
is available at https://github.com/multimodal-ai-lab/PLW.

INTRODUCTION
Users increasingly interact with modern AI systems through a single interface (Wang & Lu, 2025). In
a single continuous chat, users can ask for writing assistance, upload images for interpretation, request
visual edits, and generate entirely new images, all without switching models or losing context. This
seamless interaction has rapidly become a defining feature of deployed multimodal assistants, where
text generation, image understanding, and image synthesis coexist inside the same conversational
thread. The appeal is obvious: users no longer need separate tools for different modalities, but
instead interact with a single persistent system that carries context across tasks. The open-source
ecosystem is moving in the same direction. Recent unified multimodal architectures aim to replicate
this integrated user experience by processing and generating multiple modalities within a shared
framework (Xie et al., 2025a; Tong et al., 2025; Wu et al., 2025; Shukor et al., 2023). These systems
reduce engineering complexity, improve parameter efficiency, and allow users to move fluidly between
modalities without model switching (Ge et al., 2024; Team, 2024).
The same fluidity that makes these systems useful also encourages a new interaction pattern: Users
“reuse” the same chat for tasks that would previously have belonged to separate tools. A conversation
may begin as writing assistance, turn into image understanding, continue with personal advice, and
later end in image generation (Jones et al., 2025; Gu et al., 2026). Much of this earlier context is
irrelevant to the final image prompt, yet it remains present in the model’s context window. In benign
unified models, unrelated prior disclosures often have limited influence on subsequent generations,
and visual inspection alone typically does not reveal clear traces of prior context.
But what if this boundary is intentionally subverted? Figure 1 illustrates the threat model we study. A
user adopts a seemingly capable unified model from an open-source platform. The model behaves
normally under standard evaluation and produces visually faithful images. Yet it has been maliciously
modified such that selected prior conversational cues trigger an invisible watermark in later image
generations. The user sees an ordinary image; the attacker sees unintended private information.
In this work, we introduce Privacy-Leaking Watermarks (PLWs), a white-box attack in which a
unified multimodal model is trained to convert selected conversational cues into covert signals
embedded in generated images. Technically, the attack proceeds in two stages. First, we learn a
latent-space watermarking mechanism in the model’s VAE representation: a small additive residual
encodes a fixed binary message, while a paired extractor recovers that message from the final image
after re-encoding it into latent space. Second, we adversarially fine-tune the model so that a textual
trigger in the prior chat causes the model to follow a watermarked generation trajectory. Training
combines a target-matching objective for the watermarked latent with a teacher-matching objective
that preserves clean generations. We additionally optimize the model contrastively so that the target
message is more recoverable from triggered than clean outputs. The generated image appears benign
and visually similar to normal output, yet it carries a compact latent watermark that an attacker can
decode through the corresponding extractor. The attacker compares the extracted message against a
preselected target message associated with a sensitive attribute to determine whether that attribute
was expressed earlier in the conversation. Multiple target messages can be used to detect different
attributes. A poisoned model can pass standard benchmarks, function normally across tasks, and still
transform everyday conversations into surveillance opportunities. As unified multimodal systems
become more widely deployed, securing not only what they generate but also what hidden traces of
prior user context they carry forward becomes increasingly urgent. In summary, our contributions are
as follows:
• We study context leakage in unmodified unified models and find that, without adversarial
interventions, leakage from prior conversational context into later image generations is
generally limited. When detectable, it is either weak or accompanied by visible changes,
suggesting that reliable covert extraction is difficult in unmodified models.
• We demonstrate that this behavior can be adversarially exacerbated by introducing Privacy-
Leaking Watermarks: a novel type of malicious modification that invisibly encodes informa-
tion from earlier conversation history into later generated images.
• We validate PLWs on BAGEL and OMNIGEN2 across 13 sensitive-attribute triggers,
highlighting religion, mental health, and pregnancy. The attack achieves an average of
70.0% TPR at 1% FPR while largely preserving generation utility. It supports multiple
triggers per model and remains robust to common image transformations.

BACKGROUND & RELATED WORK
Unified Multimodal Models. Multimodal AI is moving from modular pipelines that connect separate
encoders through adapters (Radford et al., 2021; Alayrac et al., 2022; Li et al., 2023a) toward native
Unified Multimodal Models (UMMs). Early UMMs follow an everything-is-a-token paradigm,
quantizing images into discrete units so that perception, reasoning, and generation share a single
decoding space (Team, 2024; Wang et al., 2026). This direction has been scaled in systems such as
LIQUID (Wu et al., 2026b), SHOW-O (Xie et al., 2025a), and EMU3.5 (Cui et al., 2025).
Recent work further improves unification through specialized architectures. BAGEL (Deng et al.,
2025) uses Mixture-of-Transformer-Experts, JANUS-PRO (Chen et al., 2025) decouples visual encod-
ing paths, and TUNA-2 (Liu et al., 2026) explores encoder-free pixel modeling. In parallel, discrete
diffusion approaches (Li et al., 2026; Swerdlow et al., 2025) model multimodal generation as joint
denoising rather than purely sequential prediction. These advances make multimodal interaction more
seamless, but also create a shared pathway through which sensitive details from earlier conversation
may influence later generations in other modalities.
Watermarking in Generative Models. Watermarking is widely studied as a tool for provenance,
authorship verification, copyright protection, and model integrity in generative systems (Arabi et al.,
2025; Wen et al., 2023; Ci et al., 2024). Existing methods typically embed hidden signals into
generated images while preserving perceptual quality and robustness. Tree-Ring Watermarks (Wen
et al., 2023) imprint fingerprints through the diffusion sampling process, SEAL (Arabi et al., 2025)
makes watermarks content-aware to improve verification and resist forgery, and SleeperMark (Wang
et al., 2025) embeds model-level watermarks that persist through downstream fine-tuning.
This literature largely treats watermarking as protective infrastructure. We study its malicious
inversion. In unified multimodal models, prior text context and later image generation share the
same computational path, allowing a poisoned model to condition invisible watermarks on private
conversational cues. Thus, the watermark no longer answers only who generated this image?, but can
leak what the user said before generating it.
Backdoor and Privacy Attacks. Backdoor attacks show that pretrained models can be modified
to exhibit hidden behaviors in response to attacker-chosen triggers while appearing benign during
standard evaluation. Early work, such as BadNets (Gu et al., 2019) and Trojaning attacks (Liu
et al., 2018), demonstrated that adversaries can implant targeted behaviors during or after training,
even without access to downstream data. More recent approaches further reduce the barrier by
injecting backdoors directly through weight editing (Hong et al., 2022). These attacks primarily
target integrity, causing visible misbehavior or task failure when triggered. In parallel, recent work
proposed multimodal backdoor attacks against unified models (Braun et al., 2026) and highlights
privacy backdoors (Feng & Tramèr, 2024; Wen et al., 2024) that cause tampered models to leak
training data, while prompt-extraction attacks (Zhang et al., 2024; Hui et al., 2024; Yang et al., 2025)
demonstrate that sensitive contextual information, such as system prompts, can be recovered through
adversarial queries. These works reveal that both model parameters and contextual inputs can act as
leakage channels.
Our setting combines and extends these directions. We consider a backdoor embedded in a unified
multimodal model, but instead of causing visible misbehavior or extracting information through
queries, it covertly encodes live conversational context into generated outputs across modalities.

METHODOLOGY
We now formalize the Privacy-Leaking Watermark (PLW) and the experimental protocol for evaluating
it. We first specify the adversary and the conversational setting, then introduce the terminology used
throughout the paper. Finally, we describe the two-stage construction of PLWs: first learning a robust
latent watermarking scheme, and then binding this watermark to textual triggers through fine-tuning.
3.1
THREAT MODEL
We consider settings where user conversations are not directly accessible to the model provider or an
external adversary, for example, due to end-to-end encryption, third-party execution, or restricted
3

logging. An attacker may bypass this privacy boundary by embedding PLWs into the model, turning
generated outputs into covert carriers of private contextual information. The leakage becomes
actionable once the adversary obtains an image output, for instance, after the user shares it publicly.
The threat can arise in two ways. First, a model provider may intentionally or coercively deploy
PLW-enabled models for commercial, surveillance, or political purposes. Second, a third-party
attacker may compromise the model supply chain by implanting PLW behavior through fine-tuning
and redistributing the resulting model through open-source repositories or model hubs. In both cases,
the compromised model may retain normal benchmark performance and benign user-facing behavior
while activating hidden leakage only under specific conditions. The attack remains covert because
the embedded signal is not recognizable without knowledge of the attacker’s encoding scheme.
Once the PLW has been implanted, extraction requires neither live intervention nor access to the
originating conversation, but only subsequent access to a visual output. An attacker could, for
example, routinely scrape images from the web and scan them offline to identify affected users.
3.2
TERMINOLOGY
We define a chat as the complete textual input passed to a unified multimodal model before im-
age generation. Each chat consists of a context-prefix, which contains the preceding conversa-
tional turns, followed by the image-generation request: Generate an image of:
[image
description]. A turn is defined as a single user message together with the corresponding model
response. A central object in our setup is the trigger: a textual cue in the context prefix that refers to
the sensitive concept of interest, such as “I am pregnant.” During training and evaluation, we treat
paraphrases such as “I’m expecting” as variants of the same trigger. A context prefix is sensitive
if it contains any such variant and neutral otherwise. A message is the bit string associated with a
trigger. Although this message may contain multiple bits, it is used only as a marker for the presence
of the corresponding trigger, not to encode arbitrary conversational content. A watermark is the
imperceptible visual marker that carries this message inside the latent representation of a generated
image. Thus, in a PLW attack, the trigger appears in text, and the watermark makes this signal
recoverable from the image.
3.3
PRIVACY-LEAKING WATERMARKS
Our method proceeds in two stages: (1) learning an imperceptible but robust watermarking mechanism
in the latent space of the unified model, and (2) adversarially binding this watermark to a textual
trigger such that sensitive prior context conditionally activates watermarks during image generation.
An overview of our method and its usage for signal extraction after training is shown in Figure 2.
Stage 1. In the first stage, we construct a latent watermarking scheme over the image autoencoder of
the target model following prior work (Bui et al., 2023; Wang et al., 2025; Feng et al., 2024). Let
X ⊆[0, 1]H×W ×3 denote the image space and Z ⊆Rh×w×d the corresponding latent space. For a
binary message m ∈{0, 1}B, we train a message encoder Eϕ : {0, 1}B →Z and a corresponding
extractor Dω : Z →[0, 1]B, while keeping the model’s VAE encoder-decoder pair (E, D) frozen.
Given an image x ∈X, we compute its latent representation z = E(x) and encode the message as a
latent perturbation δ = Eϕ(m). The watermarked latent is zwm = z + δ. Decoding yields the clean
reconstruction xrec = D(z) and watermarked image xwm = D(zwm). The message is recovered
by re-encoding the watermarked image and applying the extractor: ˆm = Dω(E(xwm)). During
training, we independently sample each message bit as m ∼Bernoulli(0.5)B and jointly optimize
the message encoder and extractor to embed and recover arbitrary bit strings. The training objective
combines a binary cross-entropy loss (BCE) for message recovery with image-space regularization:

EXPERIMENTS
Model Selection. We evaluate our approach on OMNIGEN2 (Wu et al., 2026a) and BAGEL-
7B (Deng et al., 2025). Unified multimodal models that can handle multi-turn text context and
generate images remain a recent class of systems, leaving only a small set of suitable open-source
candidates. We select two of the strongest publicly available models on the ONEIG benchmark (Chang
et al., 2025). We exclude alternatives such as SHOW-O2 (Xie et al., 2025b) and EMU3.5 (Cui et al.,
2025), which showed limited ability to use multi-turn chat history as context for image generation
in our preliminary analysis (Appendix C). While we focus on diffusion-based image generation,
exploring autoregressive generation remains an interesting direction beyond the scope of this work.
Experimental Scenarios. We evaluate 13 triggers spanning health, religion, and other sensitive
attributes. Table 1 highlights three representative disclosures: being Hindu, having depression,
and being pregnant, and aggregates the remaining ten. For each trigger, we train on the exact
phrase and five paraphrases, then evaluate on five held-out paraphrases, such as training on I am
expecting and testing on My due date is coming up next month (Appendix I.1). In
every case, the trigger captures information disclosed in conversation but not intended to be exposed.
Experimental Setup. For each scenario, we construct paired clean and triggered evaluation sets
using the same MS-COCO prompt pool (Lin et al., 2014), disjoint from training, and differing only
in the conversational trigger condition. Each evaluation setting contains 500 clean chats and 500
triggered chats. We vary the conversational distance between the trigger and the final unrelated
image-generation request by inserting increasing numbers of neutral turns in between, as illustrated in
Figure 3. The main evaluation samples paraphrases of each trigger and varies the number of separating
neutral turns. We use a 48-bit message (B = 48) and optimize the encoder–extractor pair for 10k
steps with AdamW (Loshchilov & Hutter, 2019). Stage 2 uses batch size 1, a constant learning rate of
5 × 10−4, and LoRA adapters (Hu et al., 2022) on cached COCO-derived prompts with four-message
benign chat prefixes. We validate every 250 steps on 32 held-out chats. OMNIGEN2 trains for at most
2,000 steps with margin-based early stopping, while BAGEL uses 1,750 steps. On one NVIDIA
A100-SXM4-80GB, each stage takes approximately three hours.

attack success, the extractor predicts a 48-bit message ˆm for each generated image; detection remains
strong across message lengths (Appendix I.2). We use per-image bit accuracy as the detection score,

4.1
RESULTS
Context Leakage in Benign Models. Before evaluating PLWs, we first measure how much unrelated
prior context leaks into generations of unmodified unified models. For each trigger, we construct
matched neutral and sensitive chats with identical MS-COCO image prompts (Lin et al., 2014). We
generate 500 images per condition, embed them with CLIP ViT-L/14 (Radford et al., 2021), and
train binary linear probes with a 90:10 train-test split to distinguish sensitive-chat from neutral-chat
generations. Figure 4 shows almost no leakage from unmodified BAGEL, both visually (left) and
in near-chance probe scores (right). In contrast, OMNIGEN2 shows stronger context bleed-through,
especially for pregnancy, where visible traces accompany a clearly detectable signal.
Main PLW Experiments. Table 1 jointly reports in-domain MS-COCO prompts and out-of-domain
MJHQ prompts. In-domain recovery is reliable across triggers and conversational separations. For
the three named triggers, TPR@5% FPR ranges from 80.6–100.0% on OMNIGEN2 and 94.4–99.8%
on BAGEL; the remaining ten average 88.9–93.2% and 85.2–96.6%, respectively. At the stricter 1%
FPR, depression reaches 100.0% on OMNIGEN2 at every separation, while the same trigger remains
at 94.2–99.8% on BAGEL. Recovery declines moderately for BAGEL as neutral turns are added,
whereas OMNIGEN2 remains robust. Performance largely transfers to MJHQ. On OMNIGEN2,
depression remains at least 99.8% TPR@5% FPR across all separations, and the mean over the

its three named triggers stay between 91.4–99.8%. Thus, the domain shift primarily affects BAGEL’s
weaker triggers rather than the strongly bound cases. Utility is largely preserved, and several adapters
even obtain lower FID than their unmodified backbone. Such improvements are consistent with prior

some separation in several settings, but performance varies across triggers, backbones, and classifiers.
We therefore treat this experiment as a detectability baseline rather than a reliable defense.

CONCLUSION
We have shown that Privacy-Leaking Watermarks (PLWs) can expose sensitive conversational
information through later-generated images, without visible artifacts or user awareness. This creates
a novel privacy risk that standard evaluations may miss: a model can remain useful and visually
faithful while silently transforming private context into an extractable signal. A practical and
accessible defense is context-aware chat hygiene. Users and platforms should avoid reusing the same
conversation for unrelated topics, especially after sensitive disclosures. Health concerns, political
beliefs, religious affiliation, financial matters, and similar topics are safer when isolated from later
generative requests. Although we demonstrate PLWs in generated images, the mechanism may extend
to any unified model that generates multiple modalities through shared parameters. Text offers a
narrower covert channel, while images, video, and audio provide richer spaces for hidden embedding.
When poisoned, cross-modal memory can become a silent surveillance layer that carries private

context forward. With transparency, consent, and safeguards, however, the same mechanism could
support beneficial interventions such as suicide prevention.
ETHICS STATEMENT
This paper describes a novel privacy attack (Privacy-Leaking Watermarks) against unified multimodal
generative models. As with other dual-use security research, we believe the benefits of documenting
this vulnerability outweigh the risk of malicious replication. This research enables detection and
mitigation research (Section 4.3) and informs model providers and users of a previously uncharacter-
ized risk. Executing the attack requires white-box access sufficient to modify and redistribute model
weights, a capability already understood to enable various malicious behavior. We do not publicly
release poisoned model checkpoints. Our triggers span health, religion, political affiliation, financial
and employment status, sexuality, immigration status, and other personal disclosures. They illustrate
realistic profiling harms rather than target any individual or group. Used transparently, with consent
and appropriate safeguards, a similar trigger-conditioned mechanism could also serve beneficial
purposes, such as flagging conversations that indicate a risk of suicide.

TRAINING DETAILS
A.1
GENERAL TRAINING SETUP
All training uses 512×512 images and bfloat16 precision. Stage 1 trains only the message encoder
and extractor for 10,000 steps. Stage 2 freezes the backbone and Stage-1 modules and optimizes
only LoRA parameters with batch size 1, AdamW (β1 = 0.9, β2 = 0.95, ϵ = 10−15), and a constant
learning rate of 5 × 10−4.
For the main table, OMNIGEN2 trains for at most 2,000 steps with margin-based early stopping,
while BAGEL uses a fixed 1,750-step budget. We validate every 250 steps on 32 held-out chats. The
watermark strength warms up linearly over the first 500 steps, gradients are clipped at 1.0, and all
random seeds are fixed to 0.
A.2
LORA CONFIGURATION
This section details the Low-Rank Adaptation (LoRA) configurations applied to the BAGEL and
OMNIGEN2 architectures during the second stage of training.
Layer Selection.
For OMNIGEN2, LoRA adapters are integrated into all four transformer
block groups of the diffusion transformer: the 32 joint layers, the noise_refiner, the
ref_image_refiner, and the context_refiner. Within each block, the adaptation targets
the attention projections (attn.to_q, attn.to_k, attn.to_v, attn.to_out.0) and the
LuminaFeedForward projections (feed_forward.linear_1, linear_2, linear_3),
corresponding to the gate, down, and up projections respectively. Since these blocks reside entirely
within the diffusion decoder (OmniGen2Transformer2DModel), the language model backbone
responsible for text generation is untouched. One subtle exception is the context_refiner,
which processes text tokens inside the diffusion transformer: its weights are adapted, but this affects
only how textual conditioning is refined during image synthesis, not text output itself.
For BAGEL, which employs a Mixture-of-Transformers (MoT) architecture with dedicated expert
pathways for generation and understanding, adaptation is applied exclusively to the generation-expert
modules: q_proj_moe_gen, k_proj_moe_gen, v_proj_moe_gen, o_proj_moe_gen,
and the MLP submodules mlp_moe_gen.{gate,up,down}_proj. Because MoT routing
assigns text and image generation to disjoint weight sets, the understanding-expert parameters are
never updated, preserving BAGEL’s text and image-comprehension behavior bit-exactly.
Hyperparameters.
We employed a LoRA rank of r = 16 and scaling factor α = 16 on both
backbones. A dropout rate of 0.05 was applied to the LoRA branches to mitigate overfitting. All
LoRA implementations were managed via the peft library (v0.17.1). Consistent with our unified
pipeline, adapter weights are maintained as separate modules and can be merged into the base weights
for optimized inference.

Loss weights. The watermarking term carries no outer weight; its strength is set entirely by the
timestep gate, g(t) = σ(−(t−τ)/κ) with τ = 0.5 and κ = 0.01, which at this steepness is effectively
a hard cut at t = τ: the term is fully active below τ and off above it. The other weights are constants,

The asymmetry is not arbitrary tuning. Table 10 shows that the contrastive term is what suppresses
the clean path, and that the clean path only leaks on BAGEL.
Trigger sets and paraphrase sampling. A trigger is a set T† = {t†, p1, . . . , pK} of an exact phrase
and K paraphrases, all mapped to the same message m†. Each sensitive chat draws one wording
uniformly from the set and prefixes that same wording to both user messages in its training context.
We train on the exact phrase plus a random half of the paraphrases, selected once by the run’s seed,
and hold the other half out so that evaluation can separate wordings seen in training from wordings
never seen.

specific effects. Removing the watermarking term increases the bit-accuracy gap on OMNIGEN2
from 0.335 to 0.594 but reduces it on BAGEL from 0.296 to 0.123. Removing the contrastive term

watermarking objective, not merely a separator. On OMNIGEN2 it is strong enough to teach the
watermark unaided, which is why removing Lwm entirely still reaches triggered bit accuracy 0.999
there. A floor arm with both terms disabled is therefore required before the −Lwm row can be read
as a watermark-free baseline.
I.2
MESSAGE LENGTH
The payload length fixes how many bits Stage 1 must hide in a single image, so it bounds what any
watermark of this family can carry. We train four OMNIGEN2 adapters that differ only in that length
– 16, 32, 48 and 64 bits – on the trigger I like antifa, holding the recipe, data and trigger
handling of the main runs fixed, and evaluate each on in-domain prompts with the exact trigger.
Separation is flat across the whole range: AUC stays within 0.997–0.999 and TPR@5%FPR within
99.6–100.0, with no monotone trend in payload. A fourfold increase in the number of hidden bits
costs nothing measurable in recoverability, so the attack is not operating near the capacity of the
Stage-1 code at these lengths, and the 48-bit payload used throughout the main paper is a conservative
choice rather than a tuned one. We therefore report message length as a robustness check rather than
a design axis.

LIMITATIONS AND FUTURE DIRECTIONS
Our white-box threat model covers compromised open-source checkpoints and malicious providers,
but not all deployment settings. Similar behavior might also arise through data poisoning that pairs
triggered chats with watermarked images (Carlini et al., 2024). Testing PLWs under this weaker
access model remains future work.
We also do not fully explain why some triggers are more effective than others. Linguistic salience,
contextual embedding, and pretraining frequency may contribute. Finally, although trigger–watermark
associations could support disclosed safety interventions, the same mechanism enables covert profil-
ing, making transparency and safeguards essential.

CODE REPOSITORY
Our code, available at https://github.com/multimodal-ai-lab/PLW, contains the two-
stage PLW pipeline, inference and evaluation scripts, sweep configurations, and wrappers for the
evaluated unified models. Top-level entry points cover inference and both training stages, while
pyproject.toml specifies the reproducible uv environment.
The plw/ package separates the message encoder and extractor (modeling/), datasets and trigger
insertion (data/), model backends (wrappers/), metrics (evaluation/), and shared infras-
tructure (utils/). The evaluation code reports bit accuracy, ROC/AUC, TPR at fixed FPR, and
perceptual or semantic similarities.
